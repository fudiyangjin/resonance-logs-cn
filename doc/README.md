# Resonance Logs 文档维护说明

本目录是使用文档的源码，由文档站点同步并构建后发布。

| 语言 | 目录 |
|------|------|
| 简体中文 | [zh-CN/](./zh-CN/README.md) |
| English | [en-US/](./en-US/README.md) |
| 日本語 | [ja-JP/](./ja-JP/README.md) |

## 目录结构

三种语言使用**完全相同的文件路径**，站点按路径对应各语言页面。

```text
<locale>/
├── README.md               文档首页
├── getting-started/        快速入门、界面导览
├── features/
│   ├── dps/                DPS 检测
│   ├── monitor/            实时监控
│   ├── monster/            怪物监控
│   ├── minimap/            副本机制
│   ├── voice/              语音播报
│   ├── module-calc/        模组计算
│   └── app/                应用设置、监控方案、更新与托盘
├── faq.md, faq/            常见问题
└── changelog/              版本更新
shared/
├── img/                    所有语言共用的截图
└── audio/                  所有语言共用的音频
```

每个功能目录由 `README.md`（功能概览）和若干标签页组成，一个标签页对应应用里的一个标签。新增功能时按同样的结构添加，并在三种语言中各写一份。

## 写作约定

- **从用户出发**：先说明这个功能能帮用户做什么，再讲怎么设置；复杂的用法写成例子，放在对应的标签页里。
- **界面文案用占位符**：写 `{{ui:routes.tools.dps}}` 这类占位符，不要手写菜单名。构建时会替换为 `src/lib/i18n/messages/<locale>.ts` 中对应语言的文案；键不存在时构建失败。
- **菜单路径**：加粗且包含 ` → ` 的文本会渲染为菜单路径，例如 `**{{ui:routes.tools.dps}} → {{ui:routes.dps.themes}}**`。
- **提示框**：使用 `> [!NOTE]`、`> [!TIP]`、`> [!IMPORTANT]`、`> [!WARNING]`。
- **不要使用 HTML**：只允许 `<audio controls src="...">` 和 `<!-- -->` 注释。
- **链接锚点**：锚点由标题文本生成（小写，去掉标点，空格换成 `-`），例如 `## 方式三：微调音色（进阶）` → `#方式三微调音色进阶`。修改标题时，要同步修改指向它的链接。

## 例子

每个例子单独一个文件，三种语言使用相同的路径。站点会把它们列在对应功能分组的「实战案例」下，方便从左侧导航直接打开。

```text
features/monitor/examples/factor-energy.md
```

```markdown
# 自动显示因子能量与赛季节点

对应页面：[自定义监控](../custom-panel.md)

**场景**：你想在战斗中随时看到因子能量……

## 第 1 步：新建因子区

……
```

- 文件放在功能目录的 `examples/` 下，文件名用英文，三种语言保持一致。
- 一级标题是例子名称，不要加 `例：` / `Example:` 前缀。侧栏显示的就是这个标题。
- 标题下先链回对应的功能页，再写场景：`**场景**：`（英文 `**Scenario**:`，日文 `**シナリオ**：`）。
- 步骤用 `##`。
- 功能页末尾的 `## 例`（英文 `## Examples`）只保留指向这些文件的链接，不再把步骤写进功能页。
- 功能概览页的「页面结构」表用「例」列链到例子文件。
- 图片和音频相对路径比功能页多一层：`features/<功能>/examples/*.md` 用 `../../../../shared/...`。

## 版本更新

- 每个版本一个文件：`changelog/vX.Y.Z.md`，并在 `changelog/README.md` 的表格最上方加一行。
- 文件中第一个 `##` 小节写更新内容，用 `###` 分类（如「DPS / 历史」「遮罩监控相关」）。之后的 `##` 小节（注意事项、社区等）在站点上默认收起。
- 站点会自动把版本号最大的文件当作最新版本：版本更新页直接展示它的全文，文档首页的「最新更新」卡片列出每个分类的前几条，不需要额外维护。

## 图片与音频

- 唯一源文件放在 [shared/](./shared/)，不要复制到各语言目录。
- 相对路径：`faq/*.md`、`getting-started/*.md`、`changelog/*.md` 用 `../../shared/...`；`features/<功能>/*.md` 用 `../../../shared/...`。
- 各语言截图不同时，按语言区分文件名，并在对应语言的页面中引用。

## 校验

链接、锚点、图片和 `{{ui:}}` 占位符都在站点构建时校验，任何一项失效都会导致构建失败。修改文档后，在站点仓库中运行同步命令确认能通过：

```bash
node apps/web/scripts/docs/sync.mjs --source <resonance-logs-cn 目录>
```

同步会重建站点的生成目录。Windows 上如果站点的开发服务器正在运行，同步会因为目录被占用而失败，运行中的开发服务器也不会读到新页面：先停止开发服务器，同步完成后再启动。
