# HP/Shield Area

**{{ui:routes.tools.skillMonitor}} → {{ui:skillMonitor.tabs.shieldDetail}}** shows your current HP and shield absorption as horizontal bars, which helps tanks and shield-reliant classes judge how much more they can take.

## Display items

| Option | Content |
| --- | --- |
| **{{ui:skillMonitor.shieldDetail.showHpBar}}** | Current HP |
| **{{ui:skillMonitor.shieldDetail.showTotalShieldBar}}** | Total of all shields |
| **{{ui:skillMonitor.shieldDetail.showShieldEntries}}** | One row for each shield source |

## Bar style

You can set **{{ui:skillMonitor.shieldDetail.hpColor}}**, **{{ui:skillMonitor.shieldDetail.shieldColor}}** and **{{ui:skillMonitor.shieldDetail.healShieldColor}}** (shields converted from overhealing) separately, as well as the bar width.

Whether this area is shown in the overlay is controlled by **HP/Shield Area** in [Enable Window](./overlay.md).
