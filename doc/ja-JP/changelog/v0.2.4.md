# Changelog v0.2.4

## 更新内容

### DPS / 履歴

- スキル詳細に最大・最小・平均ダメージ統計を追加（DPSメーター → 設定 → ライブ / 履歴）
- 死亡リプレイで発生し得た key 衝突を修正

### プリセット

- ロードアウトをキャラクターのスペックに連携でき、職業切替時に自動変更（監視プリセット → 連携スペック）
  - 「スペックで自動切替」を有効にできます
- 森癒プリセットを追加し、他のプリセットにバフ稼働率を追加
- 烈風プリセットを追加

### オーバーレイ監視

- モンスターモニターに現在の攻撃対象の HP バーを追加（モンスターモニター → HP バー） @dilone
- リソース区を個別に表示/非表示できるように分割
- 森癒の三花カウントダウンをリソース区に追加（ライブモニター → Overlay エリア表示 → リソース区分）
  - バフ予告はこのエリアに 2202716 を関連付けます
  - S4 の新ロジックに対応。JP / Global サーバーは現時点では非対応

  ![森癒の三花カウントダウン](../../shared/img/changelog/v0.2.4_1.gif)

- Buff 検索で未収録の Buff ID を直接設定でき、結果をページ分割して検索時のカクつきを抑制
- 森語S4・灵感X6 蒼月の慰めカウンターを追加（ライブモニター → カスタムモニター → カウンターを追加）
- スキル軸に爆裂射撃、業火流星、神鎌、烈風の渦撃を追加
- 烈風の通常攻撃に派生「疾馳鋒刃」を追加し、派生「龍砲」より下に表示
- 双斧に荒川の寂滅の CD を追加
- 通常 Buff 区をリアルタイム表示していなくてもバフ稼働率を監視できない問題を修正
- ライブモニターなどを切り替える際、最小化されていれば先に復元して表示
- DPS / オーバーレイウィンドウを一括で最小化・復元するショートカットを追加（DPSメーター → 設定 → ショートカット）

### データ

- 26.9.4 星痕共鳴正式サーバー 1.2.45164.0 のデータを更新 @YozoraHoshi

## 注意事項

### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.2.4 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.2 と 0.2.1 は大規模な再構築を行っています。既存機能に問題があれば速やかにご連絡ください
- 0.2.2 はテーブルフィールドを変更しています。古い履歴レコードのエラーは想定どおりで、新しい記録は正常です
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません

### 特に注意

- コードを改変して PR せずに配布する場合は、アプリ名・バージョンなど本家の識別情報を必ず変更し、誤解を招かないようにしてください
- 閉じるボタンは右下に隠れます。ウィンドウが多い場合は隠れバーを右下へドラッグして表示できます
- よくある質問は利用マニュアルの HTML を参照してください
