# Changelog v0.2.5

## 更新内容

### DPS / 履歴

- コンパクトモードは既定でプレイヤー一覧だけに適用され、スキル詳細は通常の表のままです。必要な場合は「詳細ページにもコンパクトモードを適用」を有効にしてください（DPSメーター → テーマ → コンパクトモード）

  ![詳細ページにもコンパクトモードを適用](../../shared/img/dps/compact_3.ja-JP.png)

- 履歴タイムラインにディスラプトショット、鋭眼・ディバインボルトを追加
- 履歴の Buff カバー率をスキルレーンと曲線の間に表示するようにしました：Buff 名を省略せず表示し、プレイヤー別 / Buff 別のグループ切り替え、カバー率に含まれない非アクティブ時間の灰色斜線、レーンと同じホバー・選択・ズームに対応。タイムラインのヘッダーで展開します（初期状態は折りたたみ、展開すると自分を表示。ほかのプレイヤーは味方レーンとは別に選択でき、一覧とサマリーでは自分が先頭）。Buff カバー率サマリーは 1 行に 1 つの Buff になりました
- 履歴にメモを付けられるようになり、メモは履歴一覧に表示されます（履歴詳細 → メモを編集）
- 履歴の保持件数を設定可能に。既定はお気に入り以外 200 件で、1〜2000 件に変更でき、次回起動時に反映されます（アプリ設定 → 一般 → 履歴の保持）
- ダメージ属性の表示を変更：水 → 氷、木 → 森
- 難易度名がシーン名に連結されない問題を修正

### オーバーレイ監視

- 味方 CD を追加【テスト機能、実戦未検証】（モンスター監視 → 味方 CD）：同じパーティでパーティ共有を有効にしているプレイヤー同士が、すべてのスキルクールダウンをリアルタイムに共有し、表示するスキルは職業ごとに各自で選びます。既定ではゲームのチームパネルで各味方の行の横に表示し（5 人 / 20 人のチームパネルをそれぞれ 1 回位置合わせ）、リスト表示にも切り替えられます。ゲームサーバーの時刻を基準にしています
  - パーティ共有は既定で有効です。アプリ設定 → 一般 → パーティ共有 で無効にできます。サーバーは同じパーティで共有を有効にしている味方にだけデータを中継し、メモリ上にのみ保持してデータベースには書き込みません
  - 味方 CD エリアは既定で非表示です。モンスター監視 → ウィンドウを有効化 で表示してください。パーティの並び順を取得するため、アプリを起動した状態でパーティに参加してください
- モンスター監視に「エンティティ持続」を追加（モンスター監視 → エンティティ持続）：付近に出現したエンティティ（例：鎌車 179903）を ID で計時。プリセット / 手動追加と使用者範囲（自身のみ / 誰でも）に対応。出現で開始、消滅で終了。「同じ ID をまとめる」を有効にすると、同じ発動者の同じ ID のエンティティを 1 行にまとめ、残り時間が最も短いものを表示（鎌車プリセットは既定で有効）。組み込みプリセット：鎌車、ファファラ職責（領域、10 秒）、ファファラ幻想（領域、15 秒）
  - エンティティ持続エリアは既定で非表示です。モンスター監視 → ウィンドウを有効化 で表示してください
- ライブモニターの「持続時間スキル」を削除。選択済みの鎌車はモンスター監視の「エンティティ持続」へ自動移行
- モンスター監視の各エリア表示は有効化ウィンドウに統一
- モンスターの HP 数値は略記設定（西洋式 / 中国語）に従います
- 複合 Buff を追加（ライブモニター → Buff → 複合 Buff）：2〜8 個の Buff が同時に存在する（または指定数以上が存在する）とき、1 つの Buff として監視エリア、稼働率、音声に使えます

  ![複合 Buff](../../shared/img/monitor/composite_1.ja-JP.png)

- 味方 Buff は項目ごとに色を上書きでき、戦闘不能の味方を表示（モンスター監視 → 味方 Buff）
- 味方 Buff に「100ms 精度」を追加：カウントダウンを 0.1 秒単位で表示し、バーを 100ms ごとに更新します。既定はオフ（モンスター監視 → 味方 Buff）
- Buff カウントダウンアラートの秒数は直接入力になり、0.1〜60 秒を 0.1 秒単位で設定できます（ライブモニター → Buff モニター、モンスター監視 → Buff モニター）
- シーズンノードエリアは交響関連の Buff を隠さなくなりました
- シールドファイター、ヘヴィガーディアン、ディバインアーチャーのスキル CD を追加
- ミニマップに S4 レイド「蒼穹の上、昼夜の果て」第 1 ボス・ラプシスのギミックを追加
  - 巨大光槍の HP を 1 行のパーセント表示にまとめ、小金人の HP パーセントを表示
  - 「影似澄錬」の指名を表示
- オーバーレイのパフォーマンスを改善：モンスター監視のデータが変わってもすべてのパネルを再計算しなくなり、プログレスバーを単発アニメーションに変更して高リフレッシュレート時の負荷を軽減

### 音声

- フレーズ集に任意の音声ファイルをインポートできます（音声 → フレーズ集）

  ![音声をインポート](../../shared/img/voice/voice_import_1.ja-JP.png)

- スキル CD とエンティティ持続時間の読み上げを単独で設定でき、先にスキル CD 監視へ追加する必要はありません
- 音声ルールは監視プリセットとともに保存されます
- チャージスキルの残り時間が閾値をまたいだときの CD 読み上げを修正
- 再生キューを修正し、インポート音声は一括でリサンプリングするように変更

### アプリ設定

- 更新があるときにクリックするとバックグラウンドで静かにダウンロードし、完了後に検証、インストール、再起動します
- 左サイドバー下部に「使い方ガイド」を追加。現在の言語の使い方ガイドをブラウザで開きます
- 初期バージョン（0.0.1〜0.0.3）で作成されたデータベースで列が不足してエラーになる問題を修正。起動時に自動で補完します

### データ

- モンスター名、Buff、スキル効果、DBM の設定データを更新
- 誤って削除されていたモンスター名を復元

## 注意事項

### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.2.5 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.2 と 0.2.1 は大規模な再構築を行っています。既存機能に問題があれば速やかにご連絡ください
- 0.2.2 はテーブルフィールドを変更しています。古い履歴レコードのエラーは想定どおりで、新しい記録は正常です
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません

### 特に注意

- コードを改変して PR せずに配布する場合は、アプリ名・バージョンなど本家の識別情報を必ず変更し、誤解を招かないようにしてください
- 閉じるボタンは右下に隠れます。ウィンドウが多い場合は隠れバーを右下へドラッグして表示できます
- よくある質問は利用マニュアルの HTML を参照してください
