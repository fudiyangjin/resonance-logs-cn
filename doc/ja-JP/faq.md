# よくある質問

機能別に分類したよくある質問です。答えが見つからない場合は、[GitHub Issues](https://github.com/fudiyangjin/resonance-logs-cn/issues) でお気軽にご報告ください。その際は **{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.diagnostics}}** で生成したデバッグ用の圧縮ファイルを添付してください。

| 分類 | よくある質問 |
| --- | --- |
| [インストールとキャプチャ](./faq/app-runtime.md) | データが出ない、WinDivert がブロックされる、アップグレード、設定の共有、トレイ |
| [DPS とレイアウト](./faq/dps-layout.md) | 真秒間ダメージ、履歴の整理、透明ウィンドウ、タイトルバー、列設定 |
| [ライブモニター](./faq/live-monitor.md) | 表示が欠ける、ファクターエリア、Buff の別名、オーバーレイが出ない |
| [モンスターモニター](./faq/monster-monitor.md) | 対象の Buff が見えない、Boss DBM、召喚物のタイマー |
| [モジュール計算](./faq/module-calc.md) | 読み込み失敗、構成が見つからない、計算が遅い |

音声読み上げのよくある質問は [音声読み上げ · よくある質問](./features/voice/README.md#よくある質問) を参照してください。
