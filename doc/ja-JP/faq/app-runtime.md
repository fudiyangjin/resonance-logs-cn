# よくある質問 · インストールとキャプチャ

## データ取得

### データが出ない / パケットを取得できない？

次の順に一つずつ確認してください。

1. ゲームが起動していて、実際にダメージを与えていることを確認します。
2. **{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.network}}** を開き、キャプチャ方式を確認します。
3. **Npcap** を使う場合：Npcap がインストールされていることを確認し、**{{ui:settings.network.device}}** で実際にゲーム通信が流れている NIC を選択します。仮想 NIC は選ばないでください。
4. **WinDivert** を使う場合：アプリを管理者権限で実行していることを確認し、ファイアウォールやウイルス対策ソフトにブロックされていないか確認します（次の項目を参照）。
5. アプリを**完全に終了**（トレイを右クリック → **Quit**）してから再起動します。キャプチャ方式や NIC の変更は、再起動しないと反映されません。
6. 競合する可能性のある VPN、プロキシ、その他のキャプチャツールをオフにして再試行します。
7. ゲームの途中でアプリを起動した場合は、マップを 1 回切り替えます。

それでも解決しない場合は、**{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.diagnostics}}** で **{{ui:settings.debug.createDiagnosticsBundle}}** を行い、報告に添付してください。

### WinDivert と Npcap、どちらを選ぶ？

| 方式 | 説明 |
| --- | --- |
| **WinDivert** | 内蔵ドライバで追加インストール不要。管理者権限が必要で、ウイルス対策ソフトに誤検知されることがある |
| **Npcap** | [Npcap](https://npcap.com/) を別途インストールし、正しい NIC を選択する必要がある |

まずは WinDivert を試し、セキュリティソフトにブロックされる場合や NIC を指定したい場合は Npcap に切り替えてください。詳しい手順は [クイックスタート](../getting-started/README.md#3-パケット取得方法を設定) を参照してください。

### WinDivert がファイアウォールやウイルス対策ソフトにブロックされたら？

WinDivert はネットワークドライバを読み込むため、一部のセキュリティソフトはこれを危険な動作とみなします。症状としては、起動後いつまでもデータが表示されません。

1. Windows ファイアウォールでアプリの通信を許可するか、一時的にファイアウォールをオフにして、ブロックが原因かどうかを確認します。
2. ウイルス対策ソフトの隔離領域を確認し、`WinDivert.dll`、`WinDivert64.sys`、アプリのインストール先が隔離されていないことを確認します。
3. 火绒（Huorong）を使っている場合は、**防护中心 → 病毒防护 → 信任区**（信頼リスト）でアプリのインストール先を信頼に追加します。隔離領域にすでに WinDivert のファイルがある場合は、先に復元してから信頼に追加してください。
4. アプリを完全に終了してから再起動します。
5. それでも繰り返し隔離される場合は、Npcap に切り替えてください。

### スキル CD、ステータス、Buff の表示が欠ける？

ゲームは**変化した**データしか送ってきません。ゲームの途中でアプリを起動すると、アプリは完全な状態を取得できません。**マップを 1 回切り替える**（テレポート、ダンジョンへの出入り、チャンネル変更）と直ります。

## インストールと設定

### アップグレードすると設定は消える？

消えません。アプリ内の [自動アップデート](../features/app/update.md#自動更新) でも上書きインストールでも、**ユーザー設定ディレクトリを削除しない限り**、ロードアウト、テーマ、音声、履歴はすべて保持されます。

### 自分の設定を他の人に共有するには？

**{{ui:routes.tools.loadouts}}** で **{{ui:loadout.page.exportButton}}** し、得られた JSON ファイルを相手に送ります。相手は **{{ui:loadout.page.importButton}}** で取り込めば OK です。[例：ロードアウトを味方に共有する](../features/app/loadouts.md#例ロードアウトをパーティーメンバーと共有する) を参照してください。

外観、ショートカット、キャプチャの設定はこの PC 固有の設定で、ロードアウトと一緒には共有されません。

### ログファイルはどこ？

**{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.diagnostics}} → {{ui:settings.debug.openLogs}}**。

### 閉じるボタンを押してもアプリが動き続けている？

既定では、閉じるボタンはシステムトレイに隠れるだけです。トレイアイコンを右クリックして **Quit** を選ぶと完全に終了します。閉じるボタンで直接終了させたい場合は、**{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.general}}** で **{{ui:appSettings.behavior.exitOnClose}}** をオンにしてください。

### オーバーレイが画面外に出てしまった？

トレイアイコンを右クリックして **Reset All Windows** を選ぶと、すべてのウィンドウが既定の位置とサイズに戻ります。

### 監視設定が自動で復元されたというメッセージが出た？

監視設定ファイルが破損すると、アプリは自動で復元し、元のファイルも保持します。詳しくは [設定の復元](../features/app/update.md#設定の復旧) を参照してください。

### 0.0.2 / 0.0.3 からアップグレードしたら不具合が出る？

ごく初期のバージョンからアップグレードした場合のみ該当します。アプリを終了し、`%LOCALAPPDATA%\resonance-logs-cn` ディレクトリ内の `resonance-logs-cn.db` を削除してから再起動してください。
