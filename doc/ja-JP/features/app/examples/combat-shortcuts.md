# ショートカットで戦闘中にオーバーレイを調整する

関連ページ：[アプリ設定](../README.md)

**シナリオ**：ゲームをフルスクリーンで遊んでいて、オーバーレイを動かしたりデータを消したりするためにメインウィンドウへ戻りたくありません。木人を殴る前にワンキーで集計をリセットし、オーバーレイが視界を遮るときはワンキーでレイアウト編集に入り、スクリーンショットを撮るときはワンキーですべてのウィンドウを収納したいとします。

## ステップ 1：ショートカットを割り当てる

**{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.shortcuts}}** を開き、項目をクリックしてからキーの組み合わせを押します。おすすめは次のとおりです。

| 操作 | おすすめのキー |
| --- | --- |
| **{{ui:settings.shortcuts.resetEncounter}}** | `Ctrl+Shift+R` |
| **{{ui:settings.shortcuts.toggleClickthrough}}** | `Ctrl+Shift+C` |
| **{{ui:settings.shortcuts.toggleOverlayEdit}}** | `Ctrl+Shift+E` |
| **{{ui:settings.shortcuts.toggleMinimizeAll}}** | `Ctrl+Shift+H` |

割り当てを間違えたら、その項目を**右クリック**すれば解除できます。

## ステップ 2：ゲーム中に使う

- **木人を殴る前**：`Ctrl+Shift+R` を押して前回のデータを消去します。
- **DPS ウィンドウを動かす**：`Ctrl+Shift+C` を押してクリックスルーを解除し、新しい位置までドラッグしたら、もう一度押してクリックスルーに戻します。
- **監視オーバーレイを動かす**：`Ctrl+Shift+E` を押してレイアウト編集に入り、各エリアをドラッグ・拡大縮小したら、もう一度押して終了します。
- **スクリーンショットやゲームからの切り替え**：`Ctrl+Shift+H` を押して DPS ウィンドウとすべてのオーバーレイを収納し、もう一度押すと再表示します。

> [!WARNING]
> ゲームですでに使われているキーは割り当てないでください。`Ctrl+\` はゲーム標準の UI 非表示キーで、割り当てると互いに競合します。

## オーバーレイが見つからなくなったら

オーバーレイが画面外にドラッグされたり、サイズがおかしくなったりした場合は、システムトレイアイコンを右クリックして **Reset All Windows** を選ぶと、すべてのウィンドウが既定の位置に戻ります。[システムトレイ](.././update.md#システムトレイ) を参照してください。
