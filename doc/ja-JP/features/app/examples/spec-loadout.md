# スペック切り替え時にロードアウトを自動で切り替える

関連ページ：[ロードアウト](../loadouts.md)

**シナリオ**：あなたのキャラクターは普段は森癒型で、ときどき威咲型に切り替えます。ゲーム内でスペックを切り替えたら、スキル CD、Buff、DPS ウィンドウの設定が対応するものに自動で切り替わってほしく、毎回メインウィンドウに戻って手動で切り替えたくはありません。

## ステップ 1：ロードアウトを 2 つ用意する

1. **{{ui:routes.tools.loadouts}}** を開きます。
2. **{{ui:loadout.page.presetsTitle}}** で「森癒型」と「威咲型」をクリックし、それぞれロードアウトを作成します。自分のロードアウトがすでにある場合は、それをそのまま使ってください。

## ステップ 2：スペックを連携させる

各ロードアウトの **{{ui:loadout.page.linkedSpecLabel}}** ドロップダウンで、対応するスペックを選びます。

| ロードアウト | {{ui:loadout.page.linkedSpecLabel}} |
| --- | --- |
| 森癒型 | 森癒型 |
| 威咲型 | 威咲型 |
| 自動で切り替えたくないほかのロードアウト | {{ui:loadout.page.linkedSpecNone}} |

## ステップ 3：自動切替をオンにする

ページ上部の **{{ui:loadout.autoSwitch.toggle}}** をオンにします。横にある **{{ui:loadout.autoSwitch.detected}}** に、ゲーム内の現在のスペックが表示されます。

## ステップ 4：確認する

ゲーム内で威咲型に切り替えます。アプリに「「威咲型」に自動切替しました」と表示され、左サイドバーの **{{ui:loadout.sidebar.label}}** も変わり、オーバーレイの内容もそれに合わせて更新されます。

> [!TIP]
> 2 つのロードアウトで同じモンスター監視を共用する場合は、両方で同じ **{{ui:loadout.page.monsterProfileLabel}}** を選んでおけば、今後は 1 つだけ管理すれば済みます。

**{{ui:loadout.autoSwitch.detected}}** が **{{ui:loadout.autoSwitch.unknown}}** と表示される場合は、アプリがまだスペック情報を受け取っていません。一度マップを切り替えてください。
