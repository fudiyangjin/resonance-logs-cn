# ロードアウト

**ロードアウト** は、あるクラス用に用意した設定をすべて 1 つにまとめたものです。スキル CD、Buff、カスタムパネル、モンスター監視、DPS ウィンドウの設定、そしてそれらの音声設定が含まれます。クラスを変えるときはロードアウトを 1 回切り替えるだけで、すべてのオーバーレイがそれに合わせて切り替わります。

## ロードアウトの構成

| プロファイル | 含まれる内容 |
| --- | --- |
| **{{ui:loadout.page.skillProfileLabel}}** | [ライブモニター](../monitor/README.md) のスキル CD、Buff、カスタムパネル、属性パネルとその音声 |
| **{{ui:loadout.page.monsterProfileLabel}}** | [モンスターモニター](../monster/README.md) の Buff、Boss DBM、エンティティタイマーとその音声 |
| **{{ui:loadout.page.liveProfileLabel}}** | [DPS ウィンドウ](../dps/settings.md) の列、名前の表示、更新頻度など |

プロファイルは複数のロードアウトで共用できます。たとえば 2 つのアタッカークラスでスキル監視は別々にしつつ、モンスター監視は同じものを使いたい場合、両方のロードアウトで同じ **{{ui:loadout.page.monsterProfileLabel}}** を選べば、1 か所の変更が両方に反映されます。

[アプリ設定](./README.md) の外観、ショートカット、パケットキャプチャなどはロードアウトに含まれず、ロードアウトを切り替えても変わりません。

## ロードアウトの管理

**{{ui:routes.tools.loadouts}}** を開くか、左サイドバーの **{{ui:loadout.sidebar.label}}** の横にある **{{ui:loadout.sidebar.manage}}** をクリックします。

- **{{ui:loadout.page.new}}**：空のロードアウトを新しく作成します。
- **{{ui:loadout.page.activate}}**：このロードアウトに切り替えます。左サイドバーの **{{ui:loadout.sidebar.label}}** から直接切り替えることもできます。
- **{{ui:loadout.page.rename}}** / **{{ui:loadout.page.duplicate}}** / **{{ui:loadout.page.delete}}**：ロードアウトは最低 1 つ残す必要があります。
- 3 つのプロファイルのドロップダウンを変更して、このロードアウトで使うプロファイルを決めます。

## プリセット

**{{ui:loadout.page.presetsTitle}}** には、一部のスペック向けに設定済みのロードアウト（光盾型、光砕型、剛守型、剛身型、威咲型、森癒型、烈風型、響奏型など）が用意されています。クリックすると新しいロードアウトが作成され、それをもとに自由に変更でき、ほかのロードアウトには影響しません。初回起動時に表示される **{{ui:loadout.firstRun.title}}** も、ここにあるプリセットです。

## スペックで自動切替

1. 各ロードアウトに **{{ui:loadout.page.linkedSpecLabel}}** を設定します。たとえば「森癒型」のロードアウトを森癒型スペックに連携させます。
2. **{{ui:loadout.autoSwitch.toggle}}** をオンにします。

以降、ゲーム内でスペックを切り替えると、アプリが連携したロードアウトに自動で切り替えます。**{{ui:loadout.autoSwitch.detected}}** にはアプリが識別した現在のスペックが表示されます。**{{ui:loadout.autoSwitch.unknown}}** と表示される場合は、一度マップを切り替えてください。詳しい手順は [例：スペック切り替え時にロードアウトを自動で切り替える](#例スペック切り替え時にロードアウトを自動で切り替える) を参照してください。

## インポートとエクスポート

- **{{ui:loadout.page.exportButton}}**：各ロードアウトの右側にあるダウンロードアイコンで、ロードアウト全体（3 つのプロファイルと音声設定を含む）を 1 つの JSON ファイルとして保存します。
- **{{ui:loadout.page.importButton}}**：ほかの人が共有した JSON ファイルを選び、新しいロードアウトとしてインポートします。既存のロードアウトは上書きされません。

> [!NOTE]
> エクスポートされるのは設定だけで、生成済みの音声やインポートした効果音ファイルは含まれません。インポートした側は **{{ui:routes.tools.voice}} → {{ui:voice.tabs.bindings}}** で **{{ui:voice.bindings.generateMissing}}** をクリックすれば再生成できます。

共有の流れは [例：ロードアウトをパーティーメンバーと共有する](#例ロードアウトをパーティーメンバーと共有する) を参照してください。

## 例

### 例：スペック切り替え時にロードアウトを自動で切り替える

**シナリオ**：あなたのキャラクターは普段は森癒型で、ときどき威咲型に切り替えます。ゲーム内でスペックを切り替えたら、スキル CD、Buff、DPS ウィンドウの設定が対応するものに自動で切り替わってほしく、毎回メインウィンドウに戻って手動で切り替えたくはありません。

#### ステップ 1：ロードアウトを 2 つ用意する

1. **{{ui:routes.tools.loadouts}}** を開きます。
2. **{{ui:loadout.page.presetsTitle}}** で「森癒型」と「威咲型」をクリックし、それぞれロードアウトを作成します。自分のロードアウトがすでにある場合は、それをそのまま使ってください。

#### ステップ 2：スペックを連携させる

各ロードアウトの **{{ui:loadout.page.linkedSpecLabel}}** ドロップダウンで、対応するスペックを選びます。

| ロードアウト | {{ui:loadout.page.linkedSpecLabel}} |
| --- | --- |
| 森癒型 | 森癒型 |
| 威咲型 | 威咲型 |
| 自動で切り替えたくないほかのロードアウト | {{ui:loadout.page.linkedSpecNone}} |

#### ステップ 3：自動切替をオンにする

ページ上部の **{{ui:loadout.autoSwitch.toggle}}** をオンにします。横にある **{{ui:loadout.autoSwitch.detected}}** に、ゲーム内の現在のスペックが表示されます。

#### ステップ 4：確認する

ゲーム内で威咲型に切り替えます。アプリに「「威咲型」に自動切替しました」と表示され、左サイドバーの **{{ui:loadout.sidebar.label}}** も変わり、オーバーレイの内容もそれに合わせて更新されます。

> [!TIP]
> 2 つのロードアウトで同じモンスター監視を共用する場合は、両方で同じ **{{ui:loadout.page.monsterProfileLabel}}** を選んでおけば、今後は 1 つだけ管理すれば済みます。

**{{ui:loadout.autoSwitch.detected}}** が **{{ui:loadout.autoSwitch.unknown}}** と表示される場合は、アプリがまだスペック情報を受け取っていません。一度マップを切り替えてください。

### 例：ロードアウトをパーティーメンバーと共有する

**シナリオ**：一晩かけて森癒型のスキル CD、ファクターエリア、Boss の読み上げを設定しました。パーティーにいるもう 1 人の森癒型プレイヤーも、それを使いたがっています。

#### あなた側：エクスポート

1. **{{ui:routes.tools.loadouts}}** を開きます。
2. 共有したいロードアウトの右側にあるダウンロードアイコン（**{{ui:loadout.page.exportButton}}**）をクリックし、保存先を選ぶと `.json` ファイルができます。
3. そのファイルをチャットアプリなどでメンバーに送ります。

読み上げに自分で [インポートした効果音](../voice/voices.md#方法-4既存の音声をインポート) を使っている場合は、効果音の元ファイルも一緒に送ってください。

#### メンバー側：インポート

1. **{{ui:routes.tools.loadouts}}** を開き、**{{ui:loadout.page.importButton}}** をクリックして、受け取ったファイルを選びます。
2. リストに同じ名前のロードアウトが追加されるので、**{{ui:loadout.page.activate}}** をクリックします。インポートしても既存のロードアウトは上書きされず、自動で切り替わることもありません。
3. 効果音ファイルがある場合は、**{{ui:routes.tools.voice}} → {{ui:voice.tabs.phrases}}** で **{{ui:voice.phrases.import.newButton}}** から同じファイルをインポートすると、設定が自動的に対応付けられます。
4. **{{ui:voice.tabs.bindings}}** で **{{ui:voice.bindings.generateMissing}}** をクリックし、自分の PC で音声を生成します。
5. ゲームに入り、[ライブモニター](../monitor/README.md) と [モンスターモニター](../monster/README.md) でそれぞれ **レイアウト編集** を 1 回ずつクリックして、自分の解像度に合わせてオーバーレイの位置を調整します。

> [!NOTE]
> ロードアウトの連携スペックも一緒にインポートされます。メンバーが **{{ui:loadout.autoSwitch.toggle}}** をオンにしていれば、該当するスペックに切り替えたときに自動でこのロードアウトが使われます。
