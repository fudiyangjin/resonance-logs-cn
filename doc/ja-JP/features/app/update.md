# アップデート、トレイ、設定の復旧

## 自動更新

新しいバージョンがあると、左サイドバーの下部に **{{ui:updater.available}}** ボタンが表示されます。マウスを重ねると新しいバージョン番号を確認できます。

1. **{{ui:updater.available}}** をクリックすると、アプリがバックグラウンドで静かにダウンロードし、ボタンにダウンロードの進捗が表示されます。その間もダンジョン攻略を含め、普段どおりに使い続けられます。
2. ダウンロードが終わると、自動的に検証・インストールしてアプリを再起動します。
3. 途中で失敗した場合はボタンが **{{ui:updater.retry}}** に変わるので、クリックして再試行してください。

アップデートしても、ロードアウト、テーマ、音声、履歴はすべて保持されます。[ダウンロードページ](https://github.com/fudiyangjin/resonance-logs-cn/releases/latest) からインストーラーを入手して上書きインストールすることもいつでもでき、**ユーザー設定フォルダーを削除しない限り**、データが失われることはありません。

> [!TIP]
> アップデートするとアプリが再起動するため、Boss 戦の最中ではなく、戦闘と戦闘の合間にクリックすることをおすすめします。

## システムトレイ

メインウィンドウの閉じるボタンをクリックしても、既定では画面右下のトレイに隠れるだけで、オーバーレイ、集計、音声はそのまま動作します。トレイアイコンを右クリックすると次のメニューがあります。

| メニュー項目 | 動作 |
| --- | --- |
| **Show Settings** | メインウィンドウを再び開く |
| **Show Live Meter** | リアルタイム DPS ウィンドウを表示する |
| **Reset All Windows** | すべてのウィンドウを既定の位置とサイズに戻す。ウィンドウが画面外に出てしまったときに使う |
| **Disable Clickthrough** | DPS ウィンドウのクリックスルーを解除し、再びドラッグできるようにする |
| **Quit** | アプリを完全に終了する |

閉じるボタンでそのまま終了させたい場合は、**{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.general}}** で **{{ui:appSettings.behavior.exitOnClose}}** をオンにしてください。

## 設定の復旧

監視設定ファイルが破損した場合（書き込み中の停電など）、アプリは起動時に自動で使える状態に復旧し、**{{ui:monitoring.recovery.noticeTitle}}** と表示します。

- 読み込めなかった元の設定は、通知に表示される復旧フォルダーに残され、削除されません。
- ほかのアプリ設定には影響しません。

自動復旧に失敗した場合は **{{ui:monitoring.recovery.errorTitle}}** と表示されます。まず **{{ui:monitoring.recovery.reload}}** をクリックし、それでも解決しない場合は **{{ui:monitoring.recovery.openLogs}}** をクリックしたうえで、**{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.diagnostics}}** で **{{ui:settings.debug.createDiagnosticsBundle}}** を実行し、報告に添付してください。

> [!TIP]
> 定期的に [ロードアウトをエクスポート](./loadouts.md#インポートとエクスポート) しておくのが最も簡単なバックアップ方法です。OS の再インストールや PC の買い替えのときは、そのままインポートすれば元どおりです。
