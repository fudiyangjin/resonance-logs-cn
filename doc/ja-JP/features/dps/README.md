# DPSメーター

**{{ui:routes.tools.dps}}** はゲームのネットワークデータを解析し、パーティ全員のダメージ・回復・被ダメージをリアルタイムで集計します。すべての戦闘は自動で履歴に保存されるため、後から振り返ることができます。

## できること

- 戦闘中に、パーティの **DPS / HPS / 秒間被ダメージ** のランキングとスキル割合をリアルタイムで確認；
- 訓練場で **訓練用ダミーモード** を使い、決まった時間で火力をテスト；
- 戦闘後に **履歴** で、秒単位のダメージ曲線、Buff カバー率、死因を振り返り；
- チャレンジダンジョンで **チャレンジ監視** を使い、受けてはいけないギミックを受けたメンバーをマーク；
- ウィンドウの色・サイズ・列・ヘッダーを自由に調整し、画面に合わせる。

## ライブ DPS ウィンドウ

![ライブ DPS ウィンドウ](../../../shared/img/dps/dps_1.png)

ウィンドウ下部のタブで 4 つのビューを切り替えられます：

| タブ | 内容 |
| --- | --- |
| **{{ui:live.tabs.dps}}** | ダメージランキング。プレイヤーをクリックするとスキル詳細を展開 |
| **{{ui:live.tabs.heal}}** | 回復ランキングとスキル詳細 |
| **{{ui:live.tabs.tanked}}** | 被ダメージランキング |
| **{{ui:live.tabs.death}}** | 死亡記録。死亡前に受けたダメージをリプレイ可能 |

ヘッダーには既定で、戦闘タイマー、エンカウント名、総ダメージ、総 DPS、Boss HP、および **リセット / 一時停止 / 訓練用ダミー / 設定 / 最小化** ボタンが表示されます。これらは [テーマ · ヘッダー設定](./themes.md#ヘッダー設定) で追加・削除・並べ替えができます。

### スキル詳細が複数行になる理由

DPS のスキル欄はクライアントのロジックで集約されます。1 つのスキルが複数のダメージソース（例：本体ダメージ + 追加ダメージ）で構成されることがあり、スキルを展開するとこれらの内訳行が表示されます。

![スキル展開後の複数行](../../../shared/img/dps/dps_2.png)

### DPS と True DPS

| 指標 | 計算方法 |
| --- | --- |
| **DPS** | 総ダメージ ÷ 戦闘の総時間 |
| **True DPS (TDPS)** | 総ダメージ ÷ アクティブ戦闘時間（長時間の攻撃停止や移動などの空白を除外） |

戦闘時間は**最後のヒット**までを集計します。ヘッダー設定で「アクティブ戦闘時間を表示」をオンにすると、両方の時間を同時に確認できます。

## 戦闘の区切りとリセット

手動でリセットを押す必要はありません。アプリは次のルールで戦闘を自動的に区切り、履歴に保存します：

| 状況 | 動作 |
| --- | --- |
| **マップ切り替え** | 今回の戦闘にデータがあれば履歴 1 件として保存。ライブウィンドウは古いデータを残し、**次にダメージを与えたとき**にクリア |
| **マスターダンジョン** | 道中と Boss を自動で 2 件に分割 |
| **レイド** | Boss ごとに 1 件 |
| **ワイプ** | 自動リセット。次に Boss を攻撃したときに新しい区間を開始 |

> [!NOTE]
> マップ切り替え直後にライブウィンドウをすぐクリアしないのは、数値が突然消えるのを避けるためです。ヘッダーの **リセット** をクリックすれば、いつでも手動で新しい区間を始められます。

## 例

### 例：訓練用ダミーモードで 3 分間の火力を測る

**シナリオ**：モジュール構成を変えたので、訓練場でダミーを 3 分間ちょうど殴り、新旧の構成の DPS を比較したい場合です。

#### 準備

1. **{{ui:routes.tools.dps}} → {{ui:routes.dps.themes}} → {{ui:themes.tabs.live}} → {{ui:themes.header.title}}** を開き、**{{ui:themes.header.showHeaderControl}}** にチェックが入っていることを確認します。
2. **{{ui:routes.tools.dps}} → {{ui:routes.dps.settings}} → {{ui:settings.tabs.live}}** を開きます：
   - **{{ui:settings.live.trainingWindow}}** は既定の 3:03 のままにするか、好みの時間に変更；
   - **{{ui:settings.live.trainingLockPolicy}}** は **{{ui:settings.live.trainingLockPolicy.eliteDummies}}** を選択。

#### ラウンドを開始する

1. 訓練場でエリートダミーの前に立ちます。
2. ライブウィンドウのヘッダーにある**照準ボタン**をクリックすると、状態が **訓練用ダミー待機中** になります。
3. ダミーに最初の一撃を当てると自動でそのダミーがロックされ、状態が **訓練用ダミー計測中** になり、同時に計測が始まります。
4. 設定した時間に達すると状態が **区間終了** になり、ライブウィンドウが固定され、データが履歴にも保存されます。

```text
待機中 ──初回命中──▶ 計測中 ──時間切れ──▶ 区間終了
   ▲                                        │
   └──────────── 「リセット」をクリック ────────┘
```

#### 次のラウンドと比較

- ラウンド終了後にもう一度攻撃しても、新しいラウンドは自動では**始まりません**。先に **リセット** をクリックして待機中に戻してください。これにより、落ち着いて装備を替えたり CD が戻るのを待ってから始めたりできます。
- 計測中でも **リセット** をクリックすればそのラウンドを破棄できます。
- 各ラウンドは **{{ui:routes.dps.history}}** に保存されます。**お気に入りに追加** して「お気に入りのみ」で絞り込めば、複数ラウンドを並べて比較できます。

> [!WARNING]
> マップ切り替え、チャンネル変更、ギルドへの出入りで訓練用ダミーモードは自動的に解除されます。戻ったら照準ボタンをもう一度クリックしてください。

> [!TIP]
> 訓練場にいない場合は、訓練ロックを **{{ui:settings.live.trainingLockPolicy.firstMonster}}** に変更すると、フィールドで最初に命中させたモンスターに対して計測できます。単体向けのスキル回しのテストに便利です。
