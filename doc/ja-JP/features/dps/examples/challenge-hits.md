# チャレンジダンジョンで浮遊砲を受けたのは誰か確認する

関連ページ：[チャレンジ監視](../challenge.md)

**シナリオ**：N17 墓煌には「浮遊砲に当たらない」というチャレンジ目標があります。戦闘が終わってから気づくのではなく、途中でチャレンジが失敗しているかどうかを知りたい場合です。

## 設定

1. **{{ui:routes.tools.dps}} → {{ui:routes.dps.challenge}}** を開きます。
2. プリセット **{{ui:challengeWatch.preset.n17Fuyoupao}}** をクリックします。または **{{ui:challengeWatch.group.new}}** を押し、**{{ui:challengeWatch.group.addDamage}}** で「浮遊砲」やダメージ ID を検索して手動で追加します。
3. グループとして **{{ui:challengeWatch.configuredTitle}}** に表示されていることを確認します。

![チャレンジ監視ページに N17-墓煌・浮遊砲 を追加した状態](../../../../shared/img/dps/challenge_1.ja-JP.png)

## 実戦

戦闘に入ったあと、いずれかのメンバーが浮遊砲に当たると、ライブウィンドウでそのメンバーの名前の後ろに**赤い三角**が表示されます。マウスを重ねると、どのダメージが命中したか（名前・ID・命中回数）を確認できます。

![ライブウィンドウでメンバーの名前の後ろに赤い三角が表示された状態](../../../../shared/img/dps/challenge_2.ja-JP.png)

赤い三角が見えたら、すぐにやり直すかどうかを判断して時間を節約できます。

## ほかのチャレンジ

「特定のギミックを受けてはいけない」チャレンジなら、同じ方法が使えます。グループを作り、ギミック名・ダメージ名・ID で検索して追加するだけです。よく使うグループは **{{ui:challengeWatch.group.saveAsPreset}}** しておくと、ほかの装備セットでもワンクリックで追加できます。不要になったらグループを削除し、通常の戦闘で誤って警告が出ないようにしましょう。
