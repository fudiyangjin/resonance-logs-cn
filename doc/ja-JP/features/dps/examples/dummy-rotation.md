# 訓練用ダミーモードで 3 分間の火力を測る

関連ページ：[DPSメーター](../README.md)

**シナリオ**：モジュール構成を変えたので、訓練場でダミーを 3 分間ちょうど殴り、新旧の構成の DPS を比較したい場合です。

## 準備

1. **{{ui:routes.tools.dps}} → {{ui:routes.dps.themes}} → {{ui:themes.tabs.live}} → {{ui:themes.header.title}}** を開き、**{{ui:themes.header.showHeaderControl}}** にチェックが入っていることを確認します。
2. **{{ui:routes.tools.dps}} → {{ui:routes.dps.settings}} → {{ui:settings.tabs.live}}** を開きます：
   - **{{ui:settings.live.trainingWindow}}** は既定の 3:03 のままにするか、好みの時間に変更；
   - **{{ui:settings.live.trainingLockPolicy}}** は **{{ui:settings.live.trainingLockPolicy.eliteDummies}}** を選択。

## ラウンドを開始する

1. 訓練場でエリートダミーの前に立ちます。
2. ライブウィンドウのヘッダーにある**照準ボタン**をクリックすると、状態が **訓練用ダミー待機中** になります。
3. ダミーに最初の一撃を当てると自動でそのダミーがロックされ、状態が **訓練用ダミー計測中** になり、同時に計測が始まります。
4. 設定した時間に達すると状態が **区間終了** になり、ライブウィンドウが固定され、データが履歴にも保存されます。

```text
待機中 ──初回命中──▶ 計測中 ──時間切れ──▶ 区間終了
   ▲                                        │
   └──────────── 「リセット」をクリック ────────┘
```

## 次のラウンドと比較

- ラウンド終了後にもう一度攻撃しても、新しいラウンドは自動では**始まりません**。先に **リセット** をクリックして待機中に戻してください。これにより、落ち着いて装備を替えたり CD が戻るのを待ってから始めたりできます。
- 計測中でも **リセット** をクリックすればそのラウンドを破棄できます。
- 各ラウンドは **{{ui:routes.dps.history}}** に保存されます。**お気に入りに追加** して「お気に入りのみ」で絞り込めば、複数ラウンドを並べて比較できます。

> [!WARNING]
> マップ切り替え、チャンネル変更、ギルドへの出入りで訓練用ダミーモードは自動的に解除されます。戻ったら照準ボタンをもう一度クリックしてください。

> [!TIP]
> 訓練場にいない場合は、訓練ロックを **{{ui:settings.live.trainingLockPolicy.firstMonster}}** に変更すると、フィールドで最初に命中させたモンスターに対して計測できます。単体向けのスキル回しのテストに便利です。
