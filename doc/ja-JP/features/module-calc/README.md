# モジュール計算

バッグのモジュールが増えてくると、4 個や 5 個を手作業で選んでどの組み合わせが最適かを見極めるのは大変です。**{{ui:routes.tools.moduleCalc}}** は手持ちのモジュールをすべて読み込み、あらゆる組み合わせを列挙して、戦力スコアの高い上位の構成を提示します。

## データの準備

モジュールのデータはゲームから送られてくるキャラクターの全データから取得するため、手入力は不要です。

1. アプリを起動してからゲームにログインするか、**一度マップを切り替えて**、ゲームにキャラクターデータを送り直させます。
2. **{{ui:routes.tools.moduleCalc}}** を開き、**{{ui:moduleCalc.refresh}}** をクリックします。
3. **{{ui:moduleCalc.dataStatus.title}}** にモジュール数が表示されれば、読み込み成功です。

新しいモジュールを入手したり分解したりしたあとは、一度マップを切り替えてから更新してください。

## 最適な組み合わせを計算する

1. **{{ui:moduleCalc.settings.title}}** で **{{ui:moduleCalc.settings.moduleCount}}** を選びます。4 モジュールか 5 モジュールで、現在装備できるスロット数に合わせます。
2. 必要に応じてフィルター条件を設定します（後述）。何も設定しなくてもかまいません。その場合はすべてのモジュールから戦力が最も高い組み合わせを探します。
3. **{{ui:moduleCalc.start}}** をクリックし、プログレスバーが終わるまで待ちます。
4. **結果** には **{{ui:moduleCalc.results.score}}** の高い順に構成が並びます。**{{ui:moduleCalc.results.viewDetail}}** をクリックすると、各モジュールの品質、属性、属性合計値を確認できます。

### スコアの計算方法

構成のスコアは、そのモジュールの組み合わせによって得られる戦力に対応し、主に次の 2 つで決まります。

- **各属性のレベル**：組み合わせ内の同じ属性の数値が合算され、1 / 4 / 8 / 12 / 16 / 20 ポイントに達するとそれぞれレベル 1～6 に上がります。レベルが高いほど戦力が増え、名前に「極・」が付く特殊属性（例：極・ダメージ増強）は基本属性よりも効果が大きくなります。
- **属性合計値**：すべての属性の数値の合計です。

そのため、多くの属性にポイントを分散させるより、少数の属性を高いしきい値（たとえば 16 や 20）まで積み上げたほうが、たいていは有利です。

## フィルター設定

| 設定 | 効果 | 使いどころ |
| --- | --- | --- |
| **合計値が以下のモジュールを除外** | 属性合計値が設定値より低いモジュールを計算から外す | モジュールが多く計算が遅いときに、明らかに不要なモジュールを先に除外する |
| **対象属性** | 選んだ属性を持つモジュールだけを計算する | 特定の属性だけが欲しいとき。モジュールが 1000 個を超える場合も、まずこれで範囲を絞るのがおすすめ |
| **{{ui:moduleCalc.filters.excludeAttributes}}** | 選んだ属性を持つモジュールを計算から外す | 自分のクラスにまったく役立たない属性があるとき |
| **{{ui:moduleCalc.filters.minRequirements}}** | 構成内のある属性の合計値が設定値に達している必要がある | ある属性を最低でも特定のレベルにしたいとき。例：合計 ≥ 16 |

**{{ui:moduleCalc.dataStatus.title}}** には、総モジュール数と合計値フィルター後の数が同時に表示されるので、調整の目安にできます。

> [!TIP]
> 最小属性要件は対象属性よりも精密です。対象属性が保証するのは「モジュールにその属性が付いている」ことだけですが、最小属性要件は「構成全体で合計が足りている」ことを保証します。両方を併用することもできます。

## GPU アクセラレーション

モジュールが多く 5 モジュールを選んだ場合、組み合わせの数は非常に大きくなります。**{{ui:moduleCalc.settings.gpuAcceleration}}** には、**{{ui:moduleCalc.settings.cuda}}** と **{{ui:moduleCalc.settings.opencl}}** が **{{ui:moduleCalc.settings.available}}** かどうかが表示されます。

- NVIDIA のグラフィックカードでは通常 CUDA を使えます。ほかのグラフィックカードでは OpenCL を使えます。
- どちらも使えない場合は自動的に CPU で計算します。結果は同じで、時間がかかるだけです。

## 例

### 例：アタッカー向けに知力 + 会心の最適な組み合わせを探す

**シナリオ**：あなたはアタッカーのクラスで、バッグには 600 個以上のモジュールがあります。気にしているのは 2 つの火力属性だけで、4 モジュールの組み合わせでどちらも最低 16 ポイントに達し、そのうえで戦力ができるだけ高い構成にしたいとします。

以下では「知力強化」と「集中・会心」を例にしますが、実際には自分のクラスに必要な属性に置き換えてください。

#### ステップ 1：データを更新する

一度マップを切り替えてから **{{ui:routes.tools.moduleCalc}}** を開き、**{{ui:moduleCalc.refresh}}** をクリックして、**{{ui:moduleCalc.dataStatus.title}}** のモジュール数がバッグと一致しているか確認します。

#### ステップ 2：範囲を絞る

1. **合計値が以下のモジュールを除外**：8 前後までドラッグし、「合計値フィルター後」の数がはっきり減るのを確認します。
2. **対象属性**：知力強化と集中・会心を選び、この 2 つの属性を持つモジュールだけを計算対象にします。
3. **{{ui:moduleCalc.filters.excludeAttributes}}**：明らかに使わない属性（例：特攻回復強化、物理耐性）を除外します。

#### ステップ 3：最小要件を設定する

**{{ui:moduleCalc.filters.minRequirements}}** で次のように設定します。

1. 1 行目のドロップダウン（初期表示は「{{ui:moduleCalc.filters.selectAttribute}}」）で知力強化を選び、右側の数値に 16 を入力します。
2. **{{ui:moduleCalc.filters.add}}** をクリックし、集中・会心 ≥ 16 をもう 1 行追加します。

#### ステップ 4：計算して比較する

1. **{{ui:moduleCalc.settings.moduleCount}}** で 4 モジュールを選び、**{{ui:moduleCalc.start}}** をクリックします。
2. 結果で **{{ui:moduleCalc.results.viewDetail}}** をクリックし、上位の構成を比較します。スコアが近い場合は、3 つ目の属性も高い構成を優先しましょう。

#### 結果が出ないときは

**{{ui:moduleCalc.error.noSolutions}}** と表示される場合は、条件をすべて同時に満たす組み合わせが存在しません。次の順に試してください。

- 最小要件を 16 から 12 に下げる
- 「合計値が以下のモジュールを除外」を下げるか解除する
- 対象属性を解除し、最小要件だけを残す

> [!TIP]
> 納得できる構成が見つかったら、各モジュールの属性をメモしておき、ゲーム内でそのとおりに装備しましょう。
