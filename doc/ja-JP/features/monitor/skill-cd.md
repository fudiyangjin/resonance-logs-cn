# スキル CD

**{{ui:routes.tools.skillMonitor}} → {{ui:skillMonitor.tabs.skillCd}}** は、選んだスキルをアイコンとしてオーバーレイに表示し、残りクールダウンをリアルタイムで表示します。

## スキルを選ぶ

1. **{{ui:skillMonitor.skillCd.class.title}}** でクラスを選ぶと、そのクラスのスキルが下に一覧表示されます。
2. **{{ui:skillMonitor.skillCd.skills.title}}** でタブごとにスキルを選びます。クラススキルはそのまま一覧表示されます。**{{ui:skillMonitor.skillCd.resonance.title}}** は名前で検索し、検索ボックスが空のときは選択済みの幻想スキルが表示されます。**{{ui:skillMonitor.skillCd.duty.title}}** は攻撃・生存・支援・図鑑に分かれています。「不屈の闘志」は2回分のチャージに対応しています。
3. 全エリア合計で最大 **10** 個のスキルを監視できます。クラス・幻想・ロールスキルでこの上限を共有します。

## エリアに分けて配置する

**{{ui:skillMonitor.skillCd.preview.title}}** では、スキルを複数のエリアに分けられます。たとえばクラススキルを1つのエリアに、幻想・ロールスキルを別のエリアに置けます。各エリアはオーバーレイで個別に移動・拡縮でき、表示スイッチはスキル CD エリアのものを共有します。

- エリアのタブをクリックすると現在のエリアが切り替わり、新しく追加したスキルは現在のエリアに入ります。エリア名は変更でき、既定は「エリア 1」「エリア 2」…です。
- 1つのスキルは1つのエリアにしか置けません。スキルカード右上の数字はそのスキルがあるエリアを示し、クリックすると現在のエリアへ移動します。
- エリアを削除すると、その中のスキルも監視対象から外れます（スキルがある場合は確認があります）。エリアは少なくとも1つ残ります。

## スキルの配置

- 各エリアの初期値は2行 × 5列で、行数・列数をそれぞれ **1～10** に設定できます。
- **{{ui:skillMonitor.skillCd.layout.gap}}** でエリア内のアイコン同士の間隔を設定します（既定 2px、0～24px）。エリア全体の大きさはオーバーレイ編集モードで拡縮します。
- 空きマスを選んでから追加すると、その位置に配置します。選択していない場合は先頭の空きマスに入ります。空きがない場合は行数や列数を増やしてください。
- 空きマスへドラッグすると移動、他のスキルへドラッグすると入れ替えます。削除しても他のスキルは移動しません。プレビューのクリックは選択のみです。
- 行数・列数を変更しても座標は保持します。スキルが枠外になる縮小は拒否されます。**{{ui:skillMonitor.skillCd.layout.compact}}** は現在の読み順で空きを詰め、グリッドを縮小します。意図した間隔もなくなります。
- Enter / Spaceで選択、Alt + 矢印キーで移動・入れ替え、Deleteで削除、Escでキャンセルできます。枠外へのドロップでは配置は変わりません。

通常表示では設定済みスキルだけを描画し、右端・下端の空白を自動で詰めます。左端・上端やスキル間の間隔は保持します。隣接する2個のスキルなら2個のアイコンだけが表示され、スキルのないエリアは表示しません。オーバーレイ編集モードでは各エリアの全マスを表示し、エリアごとに移動・拡縮できます。各スキルの配置は設定画面で行います。

スキルアイコンは暗いプレートの上に描かれ、ゲーム内のスキルボタンと同じ属性色（赤・灰・青・金・緑）で色付けされるため、明るい場面でも見やすくなっています。味方の CD も同じプレートを使います。

配置はロードアウトと一緒に保存・複製・インポート・エクスポートされます。旧設定のスキルバーは位置と拡縮を保ったまま「エリア 1」になります。スキルの全削除やクラス変更でも、各エリアとその行数・列数は保持します。

## スキル変化

一部のスキルは特定の Buff 中に別の形態へ変化し、CD アイコンと名前も自動で切り替わります。たとえばゲイルランサーの「隼投」は特定の Buff 中に「蒼斬」と表示され、フロストメイジの「吹雪」は詠唱不要の Buff 中に「瞬間吹雪」と表示されます。

## 音声読み上げ

**{{ui:skillMonitor.skillCd.voice.title}}** セクションでは、現在のクラスのスキル・幻想スキル・ロールスキルに 3 種類のイベントを設定できます。ゲーム内にスキルバーがあるため、上のクールダウン監視に追加する必要はありません。**{{ui:skillMonitor.skillCd.voice.classSkills}}**・**{{ui:skillMonitor.skillCd.resonance.title}}**・**{{ui:skillMonitor.skillCd.duty.title}}** のタブでスキルをクリックし、いずれかのイベントをオンにすると読み上げリストに追加されます。タブで印が付くのは読み上げ設定済みのスキルだけで、クールダウン監視の選択とは関係ありません：

| イベント | タイミング |
| --- | --- |
| **発動時** | スキルがクールダウンに入ったとき |
| **完了時** | クールダウンが終わったとき |
| **完了 x 秒前** | クールダウンがまもなく終わるとき（事前準備用） |

チャージ型のスキルは、**チャージが 1 つ回復するたびに**クールダウン終了とみなし、「完了時」と「完了 x 秒前」を各チャージで読み上げます。読み上げるには、[音声読み上げ](../voice/README.md) でモデルをインストールして有効化しておく必要があります。

音声読み上げとクールダウン監視は互いに影響しません。監視に追加しても外しても読み上げはそのまま残り、不要になったら **{{ui:skillMonitor.common.remove}}** で削除します。**{{ui:skillMonitor.skillCd.class.title}}** でクラスを切り替えると、現在のプロファイルのスキル読み上げがクリアされます（ほかのプロファイルは影響を受けません）。

> [!NOTE]
> 以前ここで設定していた「持続時間スキル」（鎌車など）は [モンスターモニター · エンティティ持続](../monster/entity-duration.md) に移行しました。古いプロファイルは自動で移行されます。
