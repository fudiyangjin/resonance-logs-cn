# Boss DBM

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.bossDbm}}** は、Boss がギミックスキルを使ったときにモンスターオーバーレイへ自動で**警告バー**（スキル名 + カウントダウン + プログレスバー）を表示します。DBM アドオンのような使い心地です。

## 有効化

1. **{{ui:monsterMonitor.enabled}}** がオンになっていることを確認します。
2. **{{ui:monsterMonitor.tabs.overlay}}** で **Boss DBM エリア** をオンにします（既定ではオフ）。
3. **{{ui:monsterMonitor.actions.editLayout}}** をクリックし、警告エリアを画面中央上部の目立つ位置にドラッグします。編集モードではプレースホルダーのバーが表示されるので、戦闘外でも配置できます。

監視するスキルを手動で追加する**必要はありません**。Boss が DBM タグ付きのギミックを使うと自動で表示され、終わると自動で消えます。複数同時に進行している場合は時間順に並びます。

## スキル別名

既定のスキル名はゲームデータから取得し、未登録の項目は `#スキル効果ID` と表示されます。**{{ui:monsterMonitor.bossDbm.alias.title}}** で Boss スキルを検索し、パーティで使っている呼び方を入力します。たとえばある詠唱を「頭割り」「円避け」に変更できます。

## 音声読み上げ

**{{ui:monsterMonitor.bossDbm.voice.title}}** でスキルに **発生時** の読み上げを設定すると、Boss が詠唱を始めた時点で通知が聞こえます。

別名の一覧から項目を削除すると、その読み上げも削除されます。別名を空にして入力欄から離れると既定の名前に戻り、項目と読み上げは残ります。

## スタイル

Boss DBM エリアには専用のスタイルがあります：行間隔、列間隔、フォントサイズ、名前 / 数値の色、プログレスバーの色と不透明度。

## Boss DBM とほかの機能

| 機能 | 表示内容 |
| --- | --- |
| **Boss DBM** | Boss スキルの統一カウントダウンバー。DBM イベントのある任意の戦闘 |
| [ターゲット Buff](./buff.md) | ターゲットに付いている特定 Buff の持続時間とスタック数 |
| [ダンジョンギミック](../minimap/README.md) | 対応ダンジョンの立ち位置マップとギミック通知 |

3 つとも同時にオンにできます。
