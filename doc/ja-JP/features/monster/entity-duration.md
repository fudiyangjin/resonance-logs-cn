# エンティティ持続

**モンスター監視 → エンティティ持続** タブに対応。

召喚物や地面装置などを**ゲーム内エンティティの出現 / 消滅**で計時し、**モンスターオーバーレイ**の **エンティティ監視エリア** にテキスト行（ラベル + カウントダウン + 進捗バー）で表示します。代表例：嵐刀の **鎌車**。

> 本機能はライブモニターの旧「持続時間スキル」を置き換えます。旧プロファイルで選択済みの鎌車はアップデート時に「自身のみ」の項目として自動移行されます。

## 仕組み

- ゲームはこの種のスキルに専用エンティティを生成し、エンティティは **モンスターテンプレート ID**（鎌車 = `179901`）と **使用者** を持ちます。
- 付近にエンティティが**出現**した時点で計時開始、**消滅**（破壊・期限切れ・マップ移動）で行が削除されます。スキル CD パケットや使用時刻の記録には依存しません。
- 再使用で旧エンティティが破壊され新エンティティが生成された場合、旧行が消え新しい行が再計時されます。
- **モンスター監視のマスタースイッチ**がオンの間のみオーバーレイへデータが送られます。

## プリセット

ページ内に組み込みプリセット（現在は **鎌車**：ID 179901、35 秒、自身のみ）を表示。クリックで追加。同じ ID が既にある場合はボタンが無効になります。

## 手動追加

各項目を入力して **追加** をクリック：

| 項目 | 説明 |
|------|------|
| **エンティティ ID** | 正の整数のモンスターテンプレート ID。不正な値はエラー表示 |
| **ラベル** | パネルに表示する名前。空の場合はモンスターテーブルの名前にフォールバック |
| **持続時間（秒）** | カウントダウンの長さ。**空欄ならカウントダウンなし**で、消滅まで `∞` を表示 |
| **使用者範囲** | **自身のみ**：自分が出したエンティティのみ。**誰でも**：全員分を表示し、ラベルは `<ラベル>-<使用者>` |

エンティティ ID ごとに 1 件、最大 32 件。

## 項目リスト

ラベル・秒数（空にすると `∞`）・範囲をその場で編集でき、上下移動や削除も可能。

## スタイル

**スタイル** ブロックはカスタムパネルと同じ：行間、列間、フォントサイズ、名前 / 数値 / 進捗バーの色と不透明度、テキストシャドウ、背景。

## オーバーレイ表示

- [ウィンドウを有効化](./overlay.md) で **エンティティ監視エリア** をオンにする（デフォルトでオン）。
- トップバーの **モンスターレイアウト編集** でエリアをドラッグ・リサイズ可能。編集中はプレースホルダー行を表示。
- 一致するエンティティがない場合、パネルは描画されません。
