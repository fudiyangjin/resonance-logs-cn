# アタッカーとしてタゲを取らない

関連ページ：[ヘイトリスト](../hate.md)

**シナリオ**：アタッカーとして開幕のバーストでタンクから Boss のタゲを取ってしまう（OT）ことがよくあります。ヘイト順位での自分の位置を常に見て、タンクに近づきすぎたら手を緩めたいとします。

## ステップ 1：ヘイトリストエリアをオンにする

1. **{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.overlay}}** で **ヘイトリストエリア** をオンにします（既定でオフ）。
2. **{{ui:monsterMonitor.actions.editLayout}}** をクリックし、ヘイトリストを Boss の HP バーの近くへドラッグします。Boss から視線を大きく外さずに済みます。

## ステップ 2：表示を調整する

**{{ui:monsterMonitor.tabs.hate}}** を開きます。

1. **{{ui:monsterMonitor.hate.maxDisplay}}** を 5 にします。5 人ダンジョンなら上位数人で十分です。
2. **{{ui:monsterMonitor.hate.styleTitle}}** で文字を大きくし、進捗バーを目立つ色にします。

## 結果

戦闘中にヘイト順位と各メンバーのヘイト値が表示されます。自分のバーがタンクに追いつきそうになったら、バーストを少し止めるか、ヘイトを下げるスキルを使います。

> [!TIP]
> タンクはヘイトを維持できているかの確認に使えます。複数のモンスターをまとめて釣るときは、[戦闘リスト](../roster.md) のタンクモードと組み合わせると、自分を狙っていないモンスターがわかります。
