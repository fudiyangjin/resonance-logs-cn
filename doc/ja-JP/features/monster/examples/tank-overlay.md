# ロールに合わせてモンスターオーバーレイを配置する

関連ページ：[ウィンドウを有効化](../overlay.md)

**シナリオ**：はじめてモンスターモニターを使い、既定の 2 つのエリアしか表示されていません。タンクとして、ヘイト、スタン、戦闘リスト、Boss の予告をすべて表示し、視界を邪魔しない位置に並べたいとします。

## ステップ 1：モンスターモニターをオンにする

**{{ui:routes.tools.monsterMonitor}}** を開き、**{{ui:monsterMonitor.enabled}}** がオンになっているか確認してから、ページ上部の **{{ui:monsterMonitor.actions.toggleOverlay}}** をクリックしてモンスターオーバーレイを表示します。

## ステップ 2：必要なエリアをオンにする

**{{ui:monsterMonitor.tabs.overlay}}** で、ロールに合わせてエリアをオンにします。

| ロール | おすすめのエリア |
| --- | --- |
| タンク | **ヘイトリストエリア**、**戦闘リストエリア**、**スタンバーゲージエリア**、**Boss DBM エリア** |
| アタッカー | **モンスター Buff エリア**、**スタンバーゲージエリア**、**HP バーエリア**、**Boss DBM エリア** |
| サポート | **味方 Buff エリア**、**味方 CD エリア**、**Boss DBM エリア** |

不要なエリアはオフにします。画面に出すものが少ないほど見やすくなります。タブの緑の点は、そのエリアがオーバーレイに表示中であることを示します。

## ステップ 3：位置を決める

1. **{{ui:monsterMonitor.actions.editLayout}}** をクリックします。リアルタイムデータがないエリアはプレースホルダーで表示されます。
2. ヘイトリストと戦闘リストを片側に、スタンバーと Boss の予告を画面の中央上部に置き、角をドラッグして大きさを調整します。
3. 配置が崩れたら、**位置をリセット**、**サイズをリセット** で既定に戻せます。

## 結果

ダンジョンでは各エリアが決まった位置に表示され、タンクに必要なヘイト・リスト・予告がすべて視界に入ります。

> [!TIP]
> これらのスイッチは現在のロードアウトのモンスターモニタープロファイルに保存されます。タンク用とアタッカー用のロードアウトにそれぞれ設定しておけば、ロードアウトの切り替えに合わせてオーバーレイも切り替わります。[ロードアウト](../../app/loadouts.md) を参照してください。
