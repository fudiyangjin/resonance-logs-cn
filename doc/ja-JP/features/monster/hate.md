# ヘイトリスト

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.hate}}** は現在のターゲットのヘイト順位を表示します。タンクはヘイトを維持できているか確認でき、アタッカーはタゲ取り（OT）を避けられます。

## 設定

- **{{ui:monsterMonitor.hate.maxDisplay}}**：5～20 人
- **{{ui:monsterMonitor.hate.styleTitle}}**：間隔、フォントサイズ、色、プログレスバー

> [!NOTE]
> **ヘイトリストエリア** は既定でオフです。[ウィンドウを有効化](./overlay.md) でオンにしてください。
