# モンスタースキル

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.monsterSkill}}** は周囲のモンスターが使ったスキルを監視します。いずれかのモンスターがリスト内のスキルを使うと、モンスターオーバーレイの **モンスタースキルエリア** にスキル名が表示され、設定した秒数が経つと消えます。

主な用途：DBM 警告のない雑魚の技、エリートの危険な詠唱、フィールドボスの要注意技。

## 仕組み

ゲームは視界内の各エンティティが使っているスキルをクライアントに同期しており、アプリはそれをリストと照合します。

- **対象**：周囲のあらゆるモンスター（ボスが召喚した雑魚を含む）。プレイヤーとその召喚物では反応しません；
- **表示**：1 スキル 1 行で名前のみ。カウントダウンや進行バーはありません（スキルの使用自体に持続時間がないため）；
- **表示時間**：**{{ui:monsterMonitor.monsterSkill.displaySeconds}}** 秒後に消えます。その間に再使用されるとタイマーはやり直しになります；
- **並び順**：リストの順番どおりに並ぶので、行が入れ替わることはありません；
- 使用したモンスターが倒れたり視界から外れたりしても、その行は時間切れまで表示されます。シーンを切り替えるとすべて消えます。

## Boss DBM との違い

| | Boss DBM | モンスタースキル |
| --- | --- | --- |
| 発生条件 | サーバーが警告マーカーを付けたギミック | あらゆるモンスタースキル |
| 設定 | 不要 | 監視したいスキルを追加する |
| 表示内容 | スキル名 + カウントダウン + 進行バー | スキル名のみ |

両方を同時に有効にできます。DBM 警告があるギミックなら [Boss DBM](./boss-dbm.md) で十分です。

## スキルの追加

**{{ui:monsterMonitor.monsterSkill.searchTitle}}** でスキル名・別名・ID を検索し、結果をクリックすると追加されます。

- 結果は一致度順です。ID の完全一致が先頭で、次に別名、ID の前方一致、名前の順になります；
- 結果が多いとき（数字を 1 文字だけ入力したときなど）は最初の 50 件を表示し、下部の **さらに表示** で続きを読み込めます；
- ゲームデータに未収録のスキルは、完全な ID を入力すると追加できます；
- ボススキルの ID は [履歴](../dps/history.md) タイムラインのスキルマーカーで確認できます。

各スキルは 1 件のみ、最大 32 件です。**{{ui:monsterMonitor.monsterSkill.listTitle}}** では次の操作ができます。

| 操作 | 説明 |
| --- | --- |
| **{{ui:monsterMonitor.monsterSkill.label}}** | パネルに表示する名前。空欄ならゲーム内の名前 |
| **{{ui:monsterMonitor.monsterSkill.displaySeconds}}** | 既定は 5 秒、0.5〜60 秒で設定可能 |
| 上へ / 下へ / 削除 | パネル上の順番を変える、またはエントリを削除する |

## 音声読み上げ

スキルごとに **発生時** の読み上げを設定でき、周囲のモンスターが使った瞬間に再生されます。

- 1 回の使用につき 1 回だけ読み上げます；
- エントリを削除すると音声の設定も削除されます；
- **{{ui:monsterMonitor.enabled}}** をオフにするとオーバーレイには表示されませんが、音声読み上げは動作します。

## パネルを有効にする

**{{ui:monsterMonitor.tabs.overlay}}** で **モンスタースキルエリア** をオンにし（既定はオフ）、**{{ui:monsterMonitor.actions.editLayout}}** で好きな位置へドラッグします。データがないときは、編集モードでリスト先頭のスキルがプレビュー表示されます。

パネルスタイルでは行間、文字サイズ、名前の色、文字の影、背景を調整できます。
