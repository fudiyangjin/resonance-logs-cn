# ウィンドウを有効化

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.overlay}}** では、モンスターオーバーレイにどのエリアを表示するかを設定します。

| エリア | 既定 | 内容 |
| --- | --- | --- |
| **モンスター Buff エリア** | 表示 | [ターゲット Buff](./buff.md) |
| **味方 Buff エリア** | 表示 | [味方 Buff](./teammate.md) |
| **味方 CD エリア** | 非表示 | [味方 CD](./teammate-cd.md) |
| **ヘイトリストエリア** | 非表示 | [ヘイトリスト](./hate.md) |
| **スタンバーゲージエリア** | 非表示 | [スタンバー](./status.md#スタンバー) |
| **HP バーエリア** | 非表示 | [HP バー](./status.md#hp-バー) |
| **味方幻想エリア** | 表示 | [味方幻想](./status.md#味方幻想) |
| **Boss DBM エリア** | 非表示 | [Boss DBM](./boss-dbm.md) |
| **エンティティ持続エリア** | 非表示 | [エンティティ持続](./entity-duration.md) |
| **モンスタースキルエリア** | 非表示 | [モンスタースキル](./monster-skill.md) |

ボタンをクリックすると表示を切り替えられます。

## レイアウト編集

上部の **{{ui:monsterMonitor.actions.editLayout}}** をクリックすると、各エリアをドラッグ・リサイズでき、リアルタイムデータがない場合はプレースホルダーでプレビューします。編集モードでは **位置をリセット**、**サイズをリセット** も使えます。
