# 戦闘リスト

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.roster}}** はモンスターオーバーレイの戦闘リストエリアです。現在のターゲットだけを表示する [HP バー](./status.md#hp-バー) と違い、あなたと味方が戦っている**すべての**モンスターを対象にします。

## 表示内容

あなたまたは味方と交戦中のモンスターの HP を一覧表示します。

- **攻撃対象**は最上部に固定され、★ が付きます
- **ボス**はすべて1行ずつ表示します
- **通常モンスターとエリート**は並び順の上位数体（既定 5 体）を1行ずつ表示します。既定では HP% の高い順で、あなたを攻撃していないモンスターを先に並べることもできます
- 残りは1行の小さなバーにまとめ、その中の最高 HP と最低 HP を表示します。どれだけ多くても隠れません

バーはリアルタイムに更新され、並び順の変更は最大で毎秒1回なので行が頻繁に入れ替わりません。倒されたりリセットされたモンスターはすぐにリストから外れます。

| 設定 | 効果 |
| --- | --- |
| **{{ui:monsterMonitor.roster.normalRows}}** | 1行ずつ表示する通常モンスターとエリートの数、0～20 |
| **{{ui:monsterMonitor.roster.tankMode}}** | あなた以外を攻撃しているモンスターの数と攻撃相手を見出しに表示し、それらを1行ずつ表示して行末に相手を示します |
| **{{ui:monsterMonitor.roster.notAttackingMeFirst}}** | 他の人を狙っているモンスターを先に、次にあなたを攻撃しているものと対象不明のものを並べます。各グループ内は HP 順で、1行ずつの表示枠は先に並んだモンスターから使います |
| **{{ui:monsterMonitor.roster.showHpValue}}** | % の横に HP の数値を表示します |
| **{{ui:monsterMonitor.roster.showDistance}}** | あなたとの水平距離を表示し、同名のモンスターを見分けやすくします |

## 注目スキル

**{{ui:monsterMonitor.roster.skills.title}}** で気になるモンスタースキルを選ぶと、リストのそのモンスターの**行末**にスキルの状態が表示されます。モンスター名は繰り返しません。

- これらのスキルを使えるモンスターは攻撃対象のすぐ下に、常に1行ずつ表示されます（通常モンスターとエリートの表示数には含めません）。並びは HP 順です
- 非表示にしたモンスターでも注目スキルを使えるものは、スキル欄だけの簡易行で表示され、数には含まれません
- スキルごとに1マスで、注目リストの順に固定で並びます

| 状態 | 表示 | 意味 |
| --- | --- | --- |
| クールダウン中 | 灰色のカウントダウン | 最も早く使える時刻まで。初回は開戦時の窓から、以降は使用時刻から数えます |
| 準備完了 | 琥珀色 | クールダウンが終わり、いつでも使われる可能性があります |
| 詠唱中 | 赤いバー + 残り秒数 | 詠唱中。危険な詠唱は点滅します。別のスキルを使うと早めに終わります |
| 使用直後 | 赤い ⚡ | 詠唱なしのスキルが使われました |
| 予測不可 | — | クールダウンデータがなく、使用時に知らせるだけです |

追加方法：

- **{{ui:monsterMonitor.roster.skills.fromRecent}}**：戦ったばかりのモンスターを開き、スキルにチェックを入れます。クールダウン、開戦時の窓、詠唱時間も表示されます
- スキル名または ID で検索して追加することもできます
- スキルごとに **{{ui:monsterMonitor.roster.skills.label}}** とクールダウン秒数を設定できます。空欄ならゲームのテーブルの値を使います

> [!NOTE]
> クールダウンは「最も早く使える時刻」の下限です。記録ではクールダウンより早く再使用されたことはありませんが、終わってもすぐ使うとは限りません。スクリプトで発動するスキル（複数体が同時に使うものなど）は予測できず、詠唱を中断されると実際のクールダウンが長くなり、準備完了が早めに表示されることがあります。

## モンスターの非表示

ギミックのマーカーや設置物など HP を気にする必要のないモンスターは、**{{ui:monsterMonitor.roster.blockTitle}}** で非表示にできます。モンスター ID 単位で、すべてのプロファイルとダンジョンに適用されます。非表示のモンスターはリストに表示されず、数にも含まれません。透明モンスターやフィールドマーカーなどのよくあるギミック用モンスターは既に非表示なので、追加する必要はありません。

- **{{ui:monsterMonitor.roster.recentTitle}}**：起動後にリストに入ったモンスターで、名前・種別・最大 HP・ダンジョンが表示されます。クリックで非表示にでき、再起動で消去されます
- 名前またはモンスター ID ですべてのモンスターを検索することもできます

> [!NOTE]
> **戦闘リストエリア** は既定でオフです。[ウィンドウを有効化](./overlay.md) でオンにしてください。オンのときだけリストが集計されます。
