# スタン値・HP・味方幻想

この 3 つのタブはモンスターオーバーレイの 3 つのエリアに対応しており、いずれも現在のターゲットに追従します。

## スタンバー

**{{ui:monsterMonitor.tabs.stun}}** はターゲットの現在のスタン値 / 最大スタン値を表示し、0 になるとブレイクします。パーティでブレイク中に火力を集中させるのに役立ちます。

**{{ui:monsterMonitor.stun.styleTitle}}** で色とサイズを調整できます。

## HP バー

**{{ui:monsterMonitor.tabs.hp}}** はターゲットの HP と割合を表示します。フェーズ移行や削りラインの調整に役立ちます。

**{{ui:monsterMonitor.hp.styleTitle}}** で色とサイズを調整できます。

## 味方幻想

**{{ui:monsterMonitor.tabs.fantasy}}** は味方が召喚した共鳴幻想を表示します。

- **{{ui:monsterMonitor.fantasy.showAll}}** をオンにすると、味方の幻想をすべて一覧表示します
- または名前 / MonsterId で検索し、気になるものだけを表示します

**{{ui:monsterMonitor.fantasy.styleTitle}}** で行間、フォントサイズ、色を調整できます。

> [!NOTE]
> **スタンバーゲージエリア**、**HP バーエリア** は既定でオフです。[ウィンドウを有効化](./overlay.md) でオンにしてください。
