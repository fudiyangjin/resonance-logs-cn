# 音声読み上げ

**{{ui:routes.tools.voice}}** は、大事なタイミングを音声で知らせてくれます。ティナの CD が戻った、脆弱がもうすぐ切れる、Boss が大技を撃ってくる、マッチが成立して確認待ち……といった場面で、オーバーレイをずっと見ている必要がなくなります。

音声はすべてローカルでオフライン生成・保存されます。戦闘中は生成済みの音声を再生するだけで、モデルは動かさないため、ゲームのパフォーマンスには影響しません。

## 仕組み

音声読み上げは 2 つのステップで使います。

1. **いつ、何を読み上げるかを決める**：Buff、スキル CD、モンスターモニターなどの機能ページで、イベントに読み上げ文を設定します。
2. **テキストを音声にする**：音色を選び、それらの文言から音声を生成します。内蔵のプリセット音色を使うほか、キャラクターの声をクローンしたり、既存の音声ファイルを直接インポートしたりできます。[音色とフレーズ](./voices.md) を参照してください。

## クイックスタート

1. **{{ui:routes.tools.voice}} → {{ui:voice.tabs.model}}** を開き、**{{ui:voice.model.install}}** をクリックして音声モデルをインストールします。ダウンロード元は既定で **{{ui:voice.model.downloadSourceAuto}}** になっており、通常は変更不要です。
2. **{{ui:voice.tabs.overview}}** で **{{ui:voice.overview.enabled}}** をオンにし、音量を調整します。
3. 機能ページで読み上げを 1 つ設定します（後述）。
4. **{{ui:voice.tabs.bindings}}** に戻り、**{{ui:voice.bindings.generateMissing}}** をクリックします。既定では画面言語に対応するプリセット音色が使われるので、事前準備は不要です。
5. **{{ui:voice.bindings.tryPlay}}** で試聴し、問題なければゲームに入りましょう。

> [!TIP]
> **{{ui:voice.backend.title}}** は **{{ui:voice.backend.auto}}** のままで構いません。グラフィックカードが Vulkan に対応していれば生成がかなり速くなります。**{{ui:voice.backend.missing}}** と表示される場合は、Vulkan ランタイムをインストールしてから **{{ui:voice.overview.status.refresh}}** をクリックするか、CPU に切り替えてください。

## 機能ページで読み上げを設定する

読み上げのルールは、各機能ページでその場で設定します。最もよく使う **{{ui:routes.tools.skillMonitor}} → Buff モニター** を例にすると、監視中 Buff の下にある音声読み上げブロックを展開します。

![Buff モニターで読み上げを設定](../../../shared/img/voice/voice_1.png)

1. 監視中の Buff を検索し、読み上げリストに追加します。
2. イベントにチェックを入れます：**{{ui:voice.binding.event.gained}}**、**{{ui:voice.binding.event.expiring}}**、**{{ui:voice.binding.event.lost}}**。
3. イベントごとに文言のソースを選びます。
   - **{{ui:voice.binding.source.auto}}**：名前とイベントから自動生成します。例：「ティナ 終了」。
   - **{{ui:voice.binding.source.custom}}**：自分で書きます。例：「ティナ戻った」。幻想 Buff では階級を含めることもできます。[幻想階級プレースホルダー](./playback.md#幻想階級プレースホルダー) を参照してください。
   - **{{ui:voice.binding.source.phrase}}**：フレーズ集にある既存のフレーズ（自分でインポートした音声を含む）を選びます。
4. 必要に応じて **{{ui:voice.binding.priority}}** を設定し、**{{ui:voice.binding.tryPlay}}** をクリックします。**{{ui:voice.binding.pendingGeneration}}** と表示される場合は、まだ音声が生成されていません。

読み上げを設定できる場所の一覧：

| 場所 | 使えるイベント | 例 |
| --- | --- | --- |
| [ライブモニター · Buff](../monitor/buff.md) | 獲得時 / 残り x 秒 / 終了時 | [ティナの CD が戻ったら音声で知らせる](../monitor/buff.md#例ティナの-cd-が戻ったら音声で知らせる) |
| [ライブモニター · スキル CD](../monitor/skill-cd.md) | 発動時 / 完了時 / 完了 x 秒前 | — |
| [ライブモニター · カスタムパネルのカウンター](../monitor/custom-panel.md) | 目標達成時 | — |
| [モンスターモニター · Buff](../monster/buff.md) | 獲得時 / 残り x 秒 / 終了時 | [自分が付与した脆弱を監視する](../monster/buff.md#例自分が付与した脆弱を監視し切れる前に知らせる) |
| [モンスターモニター · Boss DBM](../monster/boss-dbm.md) | 発生時 | [Boss スキルに別名を付けて音声で予告する](../monster/boss-dbm.md#例boss-スキルに別名を付けて音声で予告する) · [自分の効果音で Boss の大技を知らせる](./voices.md#例自分の効果音で-boss-の大技を知らせる) |
| [モンスターモニター · エンティティ持続時間](../monster/entity-duration.md) | 出現時 / 残り x 秒 / 消滅時 | [鎌車の残り時間を表示する](../monster/entity-duration.md#例鎌車の残り時間を表示する) |
| [ダンジョンギミック · ギミック音声読み上げ](../minimap/README.md#ギミック音声読み上げ) | 各ダンジョンで対応済みのギミック | [レイド初攻略前のミニマップ設定](../minimap/README.md#例レイド初攻略前のミニマップ設定) |
| [{{ui:voice.tabs.alerts}}](./playback.md#マッチ通知) | マッチ成立 / 準備確認 / ダンジョン投票 | [マッチ成立を聞き逃さない](./playback.md#例放置でマッチング待ちしているときにマッチ成立を聞き逃さない) |

注意点：

- スキルの読み上げは自分のキャラクターのみが対象で、先にスキルをスキル CD 監視に追加しておく必要があります。複数チャージのスキルは、**チャージが 1 つ戻るたびに**「完了」を読み上げ、「完了 x 秒前」も各チャージに適用されます。
- 「残り x 秒」「完了 x 秒前」：残り時間が更新（クールダウン短縮、Buff の短縮、ギミックの再発動など）で一気に x 秒以内になった場合は、その場で読み上げます。すでに終わっている場合（スキルが使用可能、Buff が切れた）は読み上げません。出現した時点で残りが x 秒未満の場合も読み上げません。
- エンティティの「残り x 秒」を使うには、その項目に持続時間を設定する必要があります。エンティティが早く消えた場合は「消滅」だけを読み上げます。
- エンティティの読み上げは「エンティティ ID + 範囲」単位で記録されます。範囲（自分のみ / 任意）を変更した場合は再設定が必要です。

## 読み上げ総覧

**{{ui:voice.tabs.bindings}}** は、すべての機能ページの読み上げをソース別にまとめ、各項目の対象・イベント・文言ソース・優先度・状態を表示します。ここは閲覧専用で、読み上げを新規作成することはできません。

- 状態が **{{ui:voice.bindings.status.pending}}** のときは、**{{ui:voice.bindings.generateMissing}}** をクリックします。
- 「〜へ移動」をクリックすると、該当する機能ページに移動して編集できます。

> [!NOTE]
> 音声の設定はそれぞれの監視プロファイルと一緒に保存されます。[ロードアウト](../app/loadouts.md) を切り替えたりインポートしたりしたあとは、読み上げ総覧ですべて **{{ui:voice.bindings.status.ready}}** になっているか確認することをおすすめします。PC を替えた場合は、通常もう一度生成が必要です。

## よくある質問

| 現象 | 対処 |
| --- | --- |
| 試聴すると再生に失敗する | モデルがインストール済みで、その項目の音声が生成済みか確認してください |
| 生成アクセラレーションが利用不可と表示される | Vulkan ランタイムをインストールしてから **{{ui:voice.overview.status.refresh}}** をクリックするか、CPU / 自動に切り替えてください |
| 別の音声操作が進行中と表示される | 現在のダウンロードや生成が終わるまで待つか、キャンセルしてからやり直してください |
| ダンジョンギミックページに読み上げ可能な項目がない | 現在のダンジョンはまだギミック音声に対応していません |
| `${阶数}` を書いたのに階級が読み上げられない | [幻想階級プレースホルダー](./playback.md#幻想階級プレースホルダー) を参照してください |
| 微調整音色が使えない | [方法 3：微調整音色（上級）](./voices.md#方法-3微調整音色上級) を参照してください |
