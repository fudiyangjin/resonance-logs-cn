# 再生と通知

このページでは、実戦での読み上げの順番待ちと再生のしくみ、文言に幻想の階級を含める方法、そしてマッチング待ちのときのマッチ通知について説明します。

## 再生設定

**{{ui:routes.tools.voice}} → {{ui:voice.tabs.overview}}** で設定します。

- **{{ui:voice.overview.enabled}}**：全体のスイッチです。オフにすると、どの読み上げも再生されません。
- **音量**：すべての読み上げで共通です。
- **{{ui:voice.overview.stopPlayback}}**：現在の再生をすぐに止めます。
- **{{ui:voice.overview.status.title}}**：モデル、生成エンジン、音色の数、フレーズの数を確認できます。

## 優先度とキュー

戦闘中は複数の読み上げが同時に発生することがあります。読み上げごとに **{{ui:voice.binding.priority}}** を設定できます。

| 段階 | おすすめの用途 |
| --- | --- |
| **{{ui:voice.binding.priority.default}}** | 重要でないお知らせ |
| **{{ui:voice.binding.priority.low}}** / **{{ui:voice.binding.priority.medium}}** | Buff の準備完了など、普段のローテーションのお知らせ |
| **{{ui:voice.binding.priority.high}}** | Boss の大技など、すぐに反応が必要なもの |
| **{{ui:voice.binding.priority.urgent}}** | 対処しないと全滅するギミック |

同じ優先度の読み上げは互いに割り込まず、順番に 1 つずつ再生されます。**{{ui:voice.overview.queuePolicy}}** では次の設定もオンにできます。

- **{{ui:voice.overview.queue.drop}}**：混み合っているときに、後ろに並んだ低優先度の読み上げを破棄し、通知がどんどん遅れていくのを防ぎます。
- **{{ui:voice.overview.queue.interrupt}}**：現在の読み上げより優先度が**厳密に高い**イベントだけが割り込めます。

> [!TIP]
> ほとんどの読み上げはデフォルトか低のままにし、本当に重要な少数だけを高や緊急にすると、割り込みが意味を持ちます。

## 幻想階級プレースホルダー

一部の Buff は幻想によって付与され、その元の幻想には **0～5 階** があります。読み上げで階級を言わせたい場合は、**獲得時 / 終了時** のカスタムテキストにプレースホルダーを書きます。

| プレースホルダー | 説明 |
| --- | --- |
| `${阶数}` | 中国語の書き方 |
| `${remodelLevel}` | 上と同じ意味 |

アプリが認識するのはこの 2 つの表記だけです（画面言語に関係なく、`${阶数}` は中国語の文字のまま書いてください）。プレースホルダーは、画面言語に関係なく常に「数字 + 中国語の「阶」」（例：`5阶`）に置き換えられます。たとえばカスタムテキスト「ティナ${阶数}が発効」は、ティナが 5 階のとき「ティナ5阶が発効」と読み上げられます。音色での読まれ方は試聴で確認してください。

- 有効なのは **ライブモニターの Buff** と **モンスター Buff** の「獲得時 / 終了時」だけです。「残り x 秒」、カウンター、Boss DBM、ダンジョンギミックでは階級は展開されません。
- アプリは 0～5 階それぞれに 1 本ずつ音声を生成し、さらに階級を識別できない場合のために、プレースホルダーを取り除いたフォールバック文を 1 本生成します。
- **試聴**は 5 階の例で再生されます。実戦では、そのときに識別した階級に応じて音声が選ばれます。
- 文言を変更したら、**{{ui:voice.tabs.bindings}}** で **{{ui:voice.bindings.generateMissing}}** をお忘れなく。

元の幻想の階級を識別できる Buff は、音声の設定の有無にかかわらず、オーバーレイ上でも「名前 | n階」と表示されます。完全な例は [例：ティナの CD が戻ったら音声で知らせる](../monitor/buff.md#例ティナの-cd-が戻ったら音声で知らせる) を参照してください。

## マッチ通知

**{{ui:voice.tabs.alerts}}** を使うと、ゲームから画面を切り替えている間もマッチング状況を知らせてくれます。3 種類の通知はそれぞれ個別にオンにできます。

| 通知 | 発生するタイミング |
| --- | --- |
| **{{ui:voice.alerts.matchReady.title}}** | マッチが成立し、確認が必要なとき |
| **{{ui:voice.alerts.readyCheck.title}}** | リーダーが準備確認を開始したとき |
| **{{ui:voice.alerts.teamVote.title}}** | パーティーがダンジョン突入の投票を開始したとき |

各通知の文言は既定のもの（例：「{{ui:voice.alerts.autoText.matchReady}}」）のままでも、自分で書いても、フレーズを参照してもかまいません。マッチ通知を使う場合も、先に **{{ui:voice.overview.enabled}}** をオンにしておく必要があります。

## 例

### 例：放置でマッチング待ちしているときにマッチ成立を聞き逃さない

**シナリオ**：ダンジョンのマッチング待ちをしながら、画面を切り替えて動画を見ています。マッチ成立、リーダーによる準備確認、ダンジョン突入の投票のときに音声で知らせてもらい、確認を逃さないようにしたいとします。

#### ステップ 1：音声をオンにする

**{{ui:routes.tools.voice}} → {{ui:voice.tabs.overview}}** で **{{ui:voice.overview.enabled}}** をオンにし、ゲームから画面を切り替えていてもはっきり聞こえる音量にします。

#### ステップ 2：3 種類の通知をオンにする

**{{ui:voice.tabs.alerts}}** を開き、次の 3 つをそれぞれオンにします。

- **{{ui:voice.alerts.matchReady.title}}**
- **{{ui:voice.alerts.readyCheck.title}}**
- **{{ui:voice.alerts.teamVote.title}}**

文言は既定のままでもよいですし、「早く戻って確認して」のように目立つものに変えてもかまいません。

#### ステップ 3：音声を生成する

**{{ui:voice.tabs.bindings}}** → **{{ui:voice.bindings.generateMissing}}**。この 3 つの通知は、総覧ではマッチ通知のグループに分類されます。

#### ステップ 4：優先度を設定する

マッチング関連の通知はたいてい戦闘外で発生し、戦闘中の読み上げとは重ならないので、既定のままで問題ありません。雑魚と戦いながらマッチング待ちをすることが多い場合は、ほかの読み上げに埋もれないよう **{{ui:voice.binding.priority.high}}** に設定するとよいでしょう。

> [!NOTE]
> 通知はゲームから送られてくるネットワーク通知を利用するため、アプリを起動したままにしておく必要があります（トレイに隠しておいてもかまいません）。
