# はじめに

インストールから最初の戦闘データを確認するまでの手順です。現行バージョン向けの説明です。旧バージョンからの移行は [アプリ実行 FAQ](./faq/app-runtime.md) を参照してください。

## 1. ダウンロードとインストール

Windows x64 向けの最新 Resonance Logs CN をインストールします。更新時はユーザー設定ディレクトリを保持してください。**DPSメーター → 設定 → 言語** でゲームクライアントと同じ言語を選択します。

## 2. キャプチャ方式を選ぶ

**DPSメーター → 設定 → ネットワーク** を開き、対応する二つの方式から一つを選びます。

| 方式 | 準備 | 選ぶ目安 |
| --- | --- | --- |
| WinDivert | 内蔵ドライバー。管理者として実行 | Npcap を別途インストールしたくない場合 |
| Npcap | [Npcap](https://npcap.com/) をインストールし、アダプターを選択 | 特定のアダプターを使用する場合、または WinDivert が使えない場合 |

## 3. ネットワークを設定

**WinDivert**：この方式を選択し、管理者として実行します。ドライバーがブロックされた場合は [キャプチャのトラブルシューティング](./faq/app-runtime.md) を確認してください。

**Npcap**：**ネットワークデバイス** でゲーム通信を通す実際の Ethernet または Wi-Fi アダプターを選択します。Loopback、VirtualBox、VMware などの仮想アダプターは避けてください。VPN やプロキシを使用する場合は、実際に通信が通るデバイスを確認します。

## 4. 完全終了して再起動

> **重要**：キャプチャ方式やアダプターを変更した後は、アプリを完全終了して再起動する必要があります。メインウィンドウを閉じるだけではトレイに隠れる場合があるため、トレイから終了してください。

## 5. 戦闘データを確認

1. ゲームを起動し、戦闘できる場所へ移動します。
2. **DPSメーター** のリアルタイムウィンドウを開き、対象を攻撃します。
3. キャラクターとダメージが表示されることを確認します。ゲームの途中でアプリを起動した場合は、マップを一度切り替えて状態を同期します。

## 6. データが表示されない場合

ゲームの起動、キャプチャ方式、ドライバーまたはアダプターの設定、アプリの再起動を順に確認します。詳しい手順は [アプリ実行 FAQ](./faq/app-runtime.md) を参照してください。
