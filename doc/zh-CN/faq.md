# 常见问题

按功能分类的常见问题。找不到答案时，欢迎在 [GitHub Issues](https://github.com/fudiyangjin/resonance-logs-cn/issues) 中反馈，并附上 **{{ui:routes.tools.appSettings}} → {{ui:appSettings.tabs.diagnostics}}** 中生成的调试压缩包。

| 分类 | 常见问题 |
| --- | --- |
| [安装与抓包](./faq/app-runtime.md) | 没有数据、WinDivert 被拦截、升级、分享配置、托盘 |
| [DPS 与布局](./faq/dps-layout.md) | 真秒伤、历史清理、透明窗口、标题栏、列设置 |
| [实时监控](./faq/live-monitor.md) | 显示不全、因子区、Buff 别名、浮窗不出现 |
| [怪物监控](./faq/monster-monitor.md) | 看不到目标 Buff、Boss DBM、召唤物计时 |
| [模组计算](./faq/module-calc.md) | 读取失败、没有方案、计算慢 |

语音播报的常见问题见 [语音播报 · 常见问题](./features/voice/README.md#常见问题)。
