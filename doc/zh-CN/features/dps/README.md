# DPS 检测

**{{ui:routes.tools.dps}}** 通过解析游戏网络数据，实时统计队伍中每个人的伤害、治疗与承伤，并把每场战斗自动存入历史，方便事后复盘。

## 你可以用它做什么

- 战斗中实时查看队伍 **秒伤 / 秒疗 / 秒承伤** 排名与技能占比；
- 在训练场用 **打桩模式** 固定时长测试输出；
- 打完后在 **历史记录** 中逐秒复盘伤害曲线、Buff 覆盖与死亡原因；
- 挑战本中用 **挑战监控** 标记谁吃了不该吃的机制；
- 自由调整窗口的颜色、大小、列和标题栏，让它贴合你的屏幕。

## 实时 DPS 窗口

![实时 DPS 窗口](../../../shared/img/dps/dps_1.png)

窗口底部的标签可以在四个视图间切换：

| 标签 | 内容 |
| --- | --- |
| **{{ui:live.tabs.dps}}** | 伤害排名，点击某位玩家可展开技能明细 |
| **{{ui:live.tabs.heal}}** | 治疗排名与技能明细 |
| **{{ui:live.tabs.tanked}}** | 承伤排名 |
| **{{ui:live.tabs.death}}** | 死亡记录，可回放死亡前受到的伤害 |

标题栏默认显示战斗计时、场景名称、总伤害、总 DPS、Boss 血量，以及 **重置 / 暂停 / 打桩 / 设置 / 最小化** 按钮。这些都可以在 [主题 · 标题栏设置](./themes.md#标题栏设置) 中增删和重新排列。

### 技能明细为什么会有多条

DPS 技能栏按客户端的逻辑聚合：一个技能可能由多个伤害来源组成（例如本体伤害 + 追加伤害），展开技能后会看到这些细分条目。

![展开技能后的多条条目](../../../shared/img/dps/dps_2.png)

### 秒伤与真秒伤

| 指标 | 计算方式 |
| --- | --- |
| **秒伤 (DPS)** | 总伤害 ÷ 战斗总时长 |
| **真秒伤 (TDPS)** | 总伤害 ÷ 活跃战斗时间（排除长时间停手、跑路等空档） |

战斗时长统计到**最后一次命中**为止。在标题栏设置中开启「显示活跃战斗时间」即可同时看到两种时长。

## 战斗何时切分、何时重置

你不需要手动点重置，应用会按以下规则自动切分战斗并存入历史：

| 情况 | 行为 |
| --- | --- |
| **切换场景** | 本场有数据则存为一条历史；实时窗口保留旧数据，你**下一次造成伤害**时才清零 |
| **大师本** | 道中与 Boss 自动拆成两条记录 |
| **团本** | 每个 Boss 一条记录 |
| **团灭** | 自动重置，下次攻击 Boss 时开始新一段 |

> [!NOTE]
> 实时窗口在切图后不立刻清零，是为了避免数字突然消失。你随时可以点标题栏的 **重置** 手动开始新一段。

## 例

### 例：用打桩模式测一轮 3 分钟输出

**场景**：换了一套模组，想在训练场固定打 3 分钟木桩，对比新旧配置的秒伤。

#### 准备

1. 打开 **{{ui:routes.tools.dps}} → {{ui:routes.dps.themes}} → {{ui:themes.tabs.live}} → {{ui:themes.header.title}}**，确认 **{{ui:themes.header.showHeaderControl}}** 已勾选。
2. 打开 **{{ui:routes.tools.dps}} → {{ui:routes.dps.settings}} → {{ui:settings.tabs.live}}**：
   - **{{ui:settings.live.trainingWindow}}** 保持默认 3:03，或改成你习惯的时长；
   - **{{ui:settings.live.trainingLockPolicy}}** 选 **{{ui:settings.live.trainingLockPolicy.eliteDummies}}**。

#### 开始一轮

1. 来到训练场，站到精英木桩前。
2. 点击实时窗口标题栏的**准星按钮**，状态变为 **打桩待命**。
3. 对木桩打出第一下，自动锁定该木桩，状态变为 **打桩中**，同时开始计时。
4. 到达设定时长后，状态变为 **打桩结束**：实时窗口定格，数据同时存入历史记录。

```text
打桩待命 ──首次命中──▶ 打桩中 ──到时──▶ 打桩结束
    ▲                                    │
    └──────────────── 点击「重置」 ──────────┘
```

#### 下一轮与对比

- 打桩结束后再攻击**不会**自动开始新一轮，要先点 **重置** 回到打桩待命；这样你可以从容换装、等 CD 转好再开打。
- 打桩中途也可以点 **重置** 放弃这一轮。
- 每一轮都会保存到 **{{ui:routes.dps.history}}**，可以**加入收藏**，用「仅收藏」把几轮放在一起对比。

> [!WARNING]
> 切图、换线、进出协会会自动退出打桩模式，回来后需要重新点准星。

> [!TIP]
> 不在训练场？把打桩锁定改成 **{{ui:settings.live.trainingLockPolicy.firstMonster}}**，在野外对第一只命中的怪物计时，适合测试对单技能循环。
