# 挑战监控

**{{ui:routes.tools.dps}} → {{ui:routes.dps.challenge}}** 用来标记「禁用伤害」：只要有队员在当前战斗段中受到这些伤害，他的名字旁就会出现**红色三角**警告。

适合用在「不能被某个机制命中」的挑战目标上，打到一半就能知道挑战是否已经失败。

## 添加禁用伤害

1. 在搜索框中按机制或伤害名称搜索，例如「浮游炮」。
2. 在结果中点击添加，已添加的条目出现在 **{{ui:challengeWatch.configuredTitle}}** 中。
3. 也可以直接使用内置预设 **{{ui:challengeWatch.preset.n17Fuyoupao}}**。

![挑战监控页，搜索「浮游炮」并已添加](../../../shared/img/dps/challenge_1.zh-CN.png)

## 在哪里看到警告

红色三角会出现在实时窗口的 DPS、治疗、承伤列表中对应队员的名字后面，鼠标悬停可以看到具体受到的是哪一个伤害。

![实时窗口中某队员名字后出现红色三角](../../../shared/img/dps/challenge_2.zh-CN.png)

警告只针对**当前战斗段**，战斗切分或重置后会重新判断。

## 例

### 例：挑战本中看谁吃了浮游炮

**场景**：打 N17 墓煌时有「不被浮游炮命中」的挑战目标，你希望打到一半就知道挑战是否已经失败，而不是打完才发现。

#### 配置

1. 打开 **{{ui:routes.tools.dps}} → {{ui:routes.dps.challenge}}**。
2. 点击预设 **{{ui:challengeWatch.preset.n17Fuyoupao}}**，或者在搜索框输入「浮游炮」手动添加。
3. 确认它出现在 **{{ui:challengeWatch.configuredTitle}}** 中。

![挑战监控页已添加 N17-墓煌·浮游炮](../../../shared/img/dps/challenge_1.zh-CN.png)

#### 实战

进入战斗后，任何队员一旦被浮游炮命中，实时窗口里他的名字后面就会出现**红色三角**。鼠标悬停可以看到命中的伤害名称。

![实时窗口中队员名字后出现红色三角](../../../shared/img/dps/challenge_2.zh-CN.png)

看到红色三角，就可以决定是否直接重开，节省时间。

#### 其他挑战

同样的方法适用于任何「不能吃某个机制」的挑战：在搜索框中按机制或伤害名称搜索并添加即可。不需要时从列表中移除，避免在普通战斗中误报。
