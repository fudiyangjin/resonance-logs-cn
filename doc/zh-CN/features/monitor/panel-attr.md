# 角色面板

**{{ui:routes.tools.skillMonitor}} → {{ui:skillMonitor.tabs.panelAttr}}** 在浮窗中显示你的实时属性，例如攻速、暴击率、智力、急速、幸运，方便在战斗中确认 Buff 带来的属性变化。

## 设置

- **启用属性**：勾选要显示的属性，顶部显示「已启用 x / 总数」。
- **{{ui:skillMonitor.panelAttr.displayColor}}**：每个属性可以单独设置颜色。
- **{{ui:skillMonitor.panelAttr.rowOrder}}**：上移 / 下移调整浮窗中的排列顺序。
- **{{ui:skillMonitor.panelAttr.textStyle}}**：行间距、字体大小、名称与数值的间距。

属性显示不全或数值明显滞后时，切换一次场景即可恢复完整同步。

浮窗中是否显示这一区域，由 [启用窗口](./overlay.md) 中的 **角色属性区** 控制。
