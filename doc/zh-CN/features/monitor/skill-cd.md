# 技能 CD

**{{ui:routes.tools.skillMonitor}} → {{ui:skillMonitor.tabs.skillCd}}** 把你选中的技能以图标形式显示在浮窗中，并实时显示剩余冷却。

## 选择技能

1. 在 **{{ui:skillMonitor.skillCd.class.title}}** 中选择职业，下方会列出该职业的技能。
2. 在 **{{ui:skillMonitor.skillCd.skills.title}}** 中按分页选择技能：职业技能直接列出；**{{ui:skillMonitor.skillCd.resonance.title}}** 需要按名称搜索，已选的幻想技能在搜索框为空时会列出；**{{ui:skillMonitor.skillCd.duty.title}}** 按攻击、生存、辅助、图鉴分组，「不屈斗志」支持两层充能显示。
3. 所有区域合计最多监控 **10** 个技能，职业、幻想与职责技能共用此上限。

## 分区域摆放

在 **{{ui:skillMonitor.skillCd.preview.title}}** 中可以把技能分到多个区域，例如职业技能放一个区域，幻想、职责技能放另一个区域。每个区域在浮窗中单独拖动和缩放，共用技能 CD 区的显示开关。

- 点击区域标签切换当前区域，新加的技能会放进当前区域。可以为区域命名；默认名为「区域 1」「区域 2」……
- 同一技能只能在一个区域。技能卡片右上角的数字表示它已在哪个区域，点击即移到当前区域。
- 删除区域时，其中的技能会一起取消监控（有技能时会先确认）；至少保留一个区域。

## 调整技能布局

- 每个区域默认 2 行 × 5 列，行、列均可设置为 **1～10**。
- **{{ui:skillMonitor.skillCd.layout.gap}}** 设置该区域图标之间的距离，默认 2px，可设为 0～24px；区域整体大小在浮窗编辑模式中缩放。
- 点击空格后再添加技能，会放入该格；否则填入第一个空格。网格已满时需要增大行列。
- 拖到空格可移动，拖到已有技能上可交换。移除技能只清空对应格子，其他技能不前移。点击预览格子只会选中，不会取消监控。
- 缩小行列会保留原坐标；若有技能越界，会提示先移动。**{{ui:skillMonitor.skillCd.layout.compact}}** 按当前阅读顺序重新排列并缩小网格，会移除预留间隔。
- 键盘支持 Enter / 空格选中、Alt + 方向键移动或交换、Delete 移除、Esc 取消。拖到网格外不会改变布局。

正常浮窗只显示已配置技能，自动收起右侧、底部的空白；左侧、顶部和技能之间的预留间隔会保留。只放两个相邻技能时只显示两个图标，没有技能的区域不显示。浮窗编辑模式显示每个区域的完整网格，用于移动和缩放该区域；技能换格在配置页进行。

技能图标画在深色底板上，并按游戏技能按钮的元素色（红、灰、蓝、金、绿）染色，在明亮场景中也能看清；队友 CD 使用同样的底板。

布局随方案保存、复制和导入导出。旧方案的技能栏会成为「区域 1」，位置和缩放不变；清空技能或切换职业时保留各区域及其网格尺寸。

## 技能变换

部分技能在特定 Buff 下会变成另一种形态，CD 图标和名称会自动跟着切换。例如青岚骑士的「飞鸟投」在特定 Buff 下显示为「极·岚切」，冰法的「寒冰风暴」在免读条 Buff 下显示为「免读条的寒冰风暴」。

## 语音播报

在 **{{ui:skillMonitor.skillCd.voice.title}}** 区块中，可以为当前职业的技能、幻想技能或职责技能配置三种事件。技能不需要加入上方的 CD 监控（游戏里本来就有技能栏，只想听播报时不必再显示 CD）：在 **{{ui:skillMonitor.skillCd.voice.classSkills}}**、**{{ui:skillMonitor.skillCd.resonance.title}}**、**{{ui:skillMonitor.skillCd.duty.title}}** 分页中点击技能，打开任一事件后它就会加入播报列表。分页里只标出已配置播报的技能，与 CD 监控的选择无关。

| 事件 | 时机 |
| --- | --- |
| **释放时** | 技能进入冷却 |
| **就绪时** | 冷却结束 |
| **就绪前 x 秒** | 冷却即将结束，提前准备 |

充能类技能**每恢复一层**都算冷却结束，「就绪时」和「就绪前 x 秒」对每一层都会播报。播报的前提是已经在 [语音播报](../voice/README.md) 中安装模型并开启。

语音播报和 CD 监控互不影响：加入或取消监控都不会改动播报，不再需要时点 **{{ui:skillMonitor.common.remove}}**。在 **{{ui:skillMonitor.skillCd.class.title}}** 中切换职业会清空当前方案的技能语音播报，其他方案不受影响。

> [!NOTE]
> 以前在这里配置的「持续时间技能」（如镰车）已迁移到 [怪物监控 · 实体持续](../monster/entity-duration.md)，旧方案会自动迁移。
