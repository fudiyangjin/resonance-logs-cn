# 实体持续

对应 **怪物监控 → 实体持续** Tab。

按**游戏内实体的出现 / 消失**为召唤物、地面装置等计时，并以文字行（标签 + 倒计时 + 进度条）显示在 **怪物遮罩** 的 **实体监控区**。典型用法：岚刀的 **镰车**。

> 本功能取代了实时监控中原有的「持续时间技能」。旧方案里已勾选的镰车会在升级后自动迁移为一条「仅自己」的镰车条目。

## 原理

- 游戏会为这类技能生成一个独立实体，实体自带 **怪物模板 ID**（如镰车 = `179901`）和 **释放者**。
- 实体在附近**出现**即开始计时，**消失**（被销毁、到期、切图）即从面板移除，不依赖技能 CD 包，也不需要事先记录施放时刻。
- 若重放同一技能导致旧实体被销毁、新实体生成，旧行消失、新行重新计时。
- 只有**怪物监控总开关**开启时才会向遮罩推送数据。

## 预设

页内列出内置预设（目前为 **镰车**：ID 179901，35 秒，仅自己）。点击即添加；同一 ID 已存在时按钮禁用。

## 手动添加

填写以下字段后点击 **添加**：

| 字段 | 说明 |
|------|------|
| **实体 ID** | 正整数怪物模板 ID；不合法时提示错误 |
| **标签** | 面板上显示的名称；留空时回退为怪物表中的名称 |
| **持续时间（秒）** | 倒计时长度；**留空则不倒计时**，显示 `∞` 直到实体消失 |
| **释放者范围** | **仅自己**：只显示自己释放的实体；**任何人**：显示所有人的，标签变为 `<标签>-<释放者>` |

每个实体 ID 只保留一条配置，最多 32 条。

## 条目列表

可直接修改标签、秒数（清空即改为 `∞`）、范围，并上下移动或删除。

## 样式

**样式** 区块与自定义面板一致：行间距、列间距、字号、名称 / 数值 / 进度条颜色与透明度、文字阴影、背景。

## 遮罩显示

- 在 [启用窗口](./overlay.md) 中开启 **实体监控区**（默认开启）。
- 顶栏 **编辑怪物布局** 可拖动、缩放该区域；编辑态下会显示占位行。
- 没有匹配实体时面板不渲染。
