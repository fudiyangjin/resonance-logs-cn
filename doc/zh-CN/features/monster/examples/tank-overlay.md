# 按职责摆好怪物遮罩

对应页面：[启用窗口](../overlay.md)

**场景**：第一次使用怪物监控，打开后只看到两块默认区域。你是坦克，想把仇恨、韧性、战斗名单和 Boss 预警都打开，并排在不挡视线的位置。

## 第 1 步：打开怪物监控

打开 **{{ui:routes.tools.monsterMonitor}}**，确认已打开 **{{ui:monsterMonitor.enabled}}**，再点击页面顶部的 **{{ui:monsterMonitor.actions.toggleOverlay}}** 显示怪物遮罩。

## 第 2 步：打开需要的区域

在 **{{ui:monsterMonitor.tabs.overlay}}** 中，按职责打开对应的区域：

| 职责 | 建议打开 |
| --- | --- |
| 坦克 | **仇恨列表区**、**战斗名单区**、**韧性条区**、**Boss DBM 区** |
| 输出 | **怪物 Buff 区**、**韧性条区**、**生命条区**、**Boss DBM 区** |
| 辅助 | **队友 Buff 区**、**队友 CD 区**、**Boss DBM 区** |

不需要的区域关掉，屏幕上越少越清楚。标签上的绿点表示对应区域已经在浮窗中显示。

## 第 3 步：摆放位置

1. 点击 **{{ui:monsterMonitor.actions.editLayout}}**，没有实时数据的区域会显示占位预览。
2. 把仇恨列表和战斗名单放在一侧，韧性条和 Boss 预警放在屏幕中上方；拖动边角缩放。
3. 摆乱了可以用 **重置位置**、**重置尺寸** 恢复默认。

## 效果

进本后各区域在固定位置显示，坦克该看的仇恨、名单和预警都在视线范围内。

> [!TIP]
> 这些开关保存在当前配装的怪物监控方案里。坦克和输出配装各保存一套，切换配装时浮窗会跟着切换，见 [监控方案](../../app/loadouts.md)。
