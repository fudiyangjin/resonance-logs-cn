# 怪物技能

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.monsterSkill}}** 监控附近怪物释放的技能：任意一只怪物放出列表中的技能，怪物遮罩的 **怪物技能区** 就会显示技能名，停留设定的秒数后消失。

典型用途：没有 DBM 预警的小怪技能、精英怪的危险读条、野外首领的关键招式。

## 工作原理

游戏会把视野内每个实体当前释放的技能同步给客户端，应用据此判断：

- **来源**：附近任意怪物，包括 Boss 召唤出的小怪；玩家和玩家的召唤物不会触发；
- **显示**：一个技能一行，只显示名称，没有倒计时和进度条（释放技能本身没有持续时间）；
- **停留**：显示 **{{ui:monsterMonitor.monsterSkill.displaySeconds}}** 秒后消失；期间再次释放会重新计时；
- **顺序**：按列表顺序排列，行的位置不会跳动；
- 施法的怪物死亡或离开视野后，这一行照常显示到时间结束；切换场景时全部清空。

## 与 Boss DBM 的区别

| | Boss DBM | 怪物技能 |
| --- | --- | --- |
| 触发条件 | 服务端带预警标记的机制 | 任何怪物技能 |
| 需要配置 | 不需要 | 手动添加要监控的技能 |
| 显示内容 | 技能名 + 倒计时 + 进度条 | 只有技能名 |

两者可以同时开启。已经有 DBM 预警的机制，用 [Boss DBM](./boss-dbm.md) 即可。

## 添加技能

在 **{{ui:monsterMonitor.monsterSkill.searchTitle}}** 中按技能名称、别名或 ID 搜索，点击结果即可添加：

- 结果按匹配程度排序：ID 完全一致的排在最前，其次是别名、ID 前缀、名称；
- 结果较多时（例如只输入一个数字）先显示 50 条，点击底部 **显示更多** 继续展开；
- 游戏数据里没有收录的技能，输入完整 ID 即可添加；
- Boss 技能的 ID 可以在 [历史记录](../dps/history.md) 时间轴的技能标记里查看。

每个技能只保留一条，最多 32 条。在 **{{ui:monsterMonitor.monsterSkill.listTitle}}** 中可以：

| 操作 | 说明 |
| --- | --- |
| **{{ui:monsterMonitor.monsterSkill.label}}** | 面板上显示的名字，留空则用游戏内名称 |
| **{{ui:monsterMonitor.monsterSkill.displaySeconds}}** | 默认 5 秒，可设 0.5–60 秒 |
| 上移 / 下移 / 删除 | 调整面板上的顺序或移除条目 |

## 语音播报

每个技能可以配置 **触发时** 播报：附近怪物一释放就播。

- 同一次释放只播报一次；
- 删除条目时语音绑定一起删除；
- 关闭 **{{ui:monsterMonitor.enabled}}** 后浮窗不再显示，但语音播报照常工作。

## 开启面板

在 **{{ui:monsterMonitor.tabs.overlay}}** 中打开 **怪物技能区**（默认关闭），再点击 **{{ui:monsterMonitor.actions.editLayout}}** 把它拖到合适的位置。编辑模式下没有数据时会显示列表中前几个技能作为占位。

面板样式可以调整行间距、字号、名称颜色、文字阴影和背景。
