# 启用窗口

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.overlay}}** 控制怪物遮罩中显示哪些区域。

| 区域 | 默认 | 内容 |
| --- | --- | --- |
| **怪物 Buff 区** | 显示 | [目标 Buff](./buff.md) |
| **队友 Buff 区** | 显示 | [队友 Buff](./teammate.md) |
| **队友 CD 区** | 隐藏 | [队友 CD](./teammate-cd.md) |
| **仇恨列表区** | 隐藏 | [仇恨列表](./hate.md) |
| **韧性条区** | 隐藏 | [韧性条](./status.md#韧性条) |
| **生命条区** | 隐藏 | [生命条](./status.md#生命条) |
| **队友幻想区** | 显示 | [队友幻想](./status.md#队友幻想) |
| **Boss DBM 区** | 隐藏 | [Boss DBM](./boss-dbm.md) |
| **实体监控区** | 隐藏 | [实体持续](./entity-duration.md) |
| **怪物技能区** | 隐藏 | [怪物技能](./monster-skill.md) |

点击按钮即可切换显示。

## 编辑布局

点击顶部 **{{ui:monsterMonitor.actions.editLayout}}** 后，每个区域可以拖动和缩放，没有实时数据时显示占位预览。编辑模式下可以 **重置位置**、**重置尺寸**。
