# 战斗名单

**{{ui:routes.tools.monsterMonitor}} → {{ui:monsterMonitor.tabs.roster}}** 对应怪物遮罩中的战斗名单区。与只看当前目标的 [生命条](./status.md#生命条) 不同，它覆盖你和队友正在交战的**所有**怪物。

## 显示内容

列出与你或队友交战中的每只怪物的血量：

- **主目标**固定在最上面，带 ★；
- **Boss** 全部逐行显示；
- **普通怪和精英**按排序逐行显示前几只（默认 5 只）。默认按血量百分比从高到低排，也可以让不攻击你的怪排在前面；
- 其余的合成最后一行小竖条，并标出其中的最高和最低血量。怪再多也不会被藏掉。

血条实时更新；名次最多每秒调整一次，避免行来回跳动。怪物死亡或脱战重置后立刻从名单中移除。

| 设置 | 作用 |
| --- | --- |
| **{{ui:monsterMonitor.roster.normalRows}}** | 普通怪和精英逐行显示几只，0～20 |
| **{{ui:monsterMonitor.roster.tankMode}}** | 表头统计「不在我身上」的怪及它们在打谁；这些怪全部逐行显示，行尾标出目标 |
| **{{ui:monsterMonitor.roster.notAttackingMeFirst}}** | 目标是别人的怪排在前面，再排攻击你的和目标未知的怪，每组内仍按血量排。逐行名额先给排在前面的怪 |
| **{{ui:monsterMonitor.roster.showHpValue}}** | 在百分比旁显示具体血量 |
| **{{ui:monsterMonitor.roster.showDistance}}** | 显示与你的水平距离，方便区分同名的怪 |

## 关注技能

在 **{{ui:monsterMonitor.roster.skills.title}}** 里选出你关心的怪物技能，名单会在怪那一行的**行尾**显示技能状态，不会重复写怪名：

- 能放这些技能的怪排在主目标下面，永远逐行显示（不占普通怪和精英的逐行名额），之间按血量排序；
- 被屏蔽、但能放关注技能的怪显示为只有技能格的精简行，不计入数量；
- 每个技能一格，按关注列表的顺序固定排列。

| 状态 | 显示 | 含义 |
| --- | --- | --- |
| 冷却中 | 灰色倒计时 | 最早还要多久才可能放。开战时从开战首放窗口算起，放过之后从施放时刻算起 |
| 就绪 | 琥珀色 | 冷却已过，随时可能放 |
| 读条中 | 红色进度条 + 剩余秒数 | 正在读条；危险读条会闪烁。怪放了别的技能就提前结束 |
| 刚放出 | 红色 ⚡ | 放出了不需要读条的技能 |
| 无法预测 | — | 没有冷却数据，只在释放时提醒 |

添加方式：

- **{{ui:monsterMonitor.roster.skills.fromRecent}}**：点开一只刚打过的怪，勾选它的技能，旁边会列出冷却、开战窗口、读条时长；
- 按技能名或 ID 搜索添加；
- 每个技能可以设 **{{ui:monsterMonitor.roster.skills.label}}**，也可以自定义冷却秒数，留空则使用游戏表里的冷却。

> [!NOTE]
> 冷却是"最早可放"的下限：实测怪物从不在冷却结束前重复释放，但冷却结束后 AI 不一定马上放；脚本触发的技能（比如几只怪同时放）无法预测；读条被打断后实际冷却可能更长，就绪会显示得偏早。

## 屏蔽怪物

机制标记、场景物件这类不需要关心血量的怪，可以在 **{{ui:monsterMonitor.roster.blockTitle}}** 中屏蔽。屏蔽按怪物 ID 生效，对所有方案和副本都有效；被屏蔽的怪不出现在名单中，也不计入数量。隐身怪、场地标记等常见机制物已经默认屏蔽，不需要自己添加。

- **{{ui:monsterMonitor.roster.recentTitle}}**：本次启动后进入过名单的怪物，带名称、类型、最大血量和所在副本，点击即可屏蔽，重启后清空；
- 也可以按名称或怪物 ID 搜索全部怪物。

> [!NOTE]
> **战斗名单区** 默认关闭，需要在 [启用窗口](./overlay.md) 中打开。打开后后台才会统计名单。
