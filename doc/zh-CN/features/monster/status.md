# 韧性、生命与队友幻想

这三个标签分别对应怪物遮罩中的三块区域，都跟随当前目标。

## 韧性条

**{{ui:monsterMonitor.tabs.stun}}** 显示目标的当前韧性 / 最大韧性，降到 0 即破防。适合队伍配合在破防窗口集中爆发。

**{{ui:monsterMonitor.stun.styleTitle}}** 可以调整颜色与尺寸。

## 生命条

**{{ui:monsterMonitor.tabs.hp}}** 显示目标的生命值与百分比，适合卡阶段转换或斩杀线。

**{{ui:monsterMonitor.hp.styleTitle}}** 可以调整颜色与尺寸。

## 队友幻想

**{{ui:monsterMonitor.tabs.fantasy}}** 显示队友召唤出的共鸣幻想。

- 开启 **{{ui:monsterMonitor.fantasy.showAll}}**，列出所有队友幻想；
- 或按名称 / MonsterId 搜索，只显示你关心的几个。

**{{ui:monsterMonitor.fantasy.styleTitle}}** 可以调整行距、字号和颜色。

> [!NOTE]
> **韧性条区**、**生命条区** 默认关闭，需要在 [启用窗口](./overlay.md) 中打开。
