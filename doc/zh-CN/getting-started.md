# 快速入门

从安装到看到第一条战斗数据，按以下步骤完成配置。适用于当前版本；旧版本迁移要求见 [应用运行 FAQ](./faq/app-runtime.md)。

## 1. 下载并安装

安装最新的 Resonance Logs CN Windows x64 版本。升级时保留用户设置目录。界面语言可在 **DPS检测 → 设置 → 语言** 中选择，与游戏客户端保持一致。

## 2. 选择抓包方式

打开 **DPS检测 → 设置 → 网络**。应用支持两种方式，选择一种即可。

| 方式 | 准备工作 | 适合情况 |
| --- | --- | --- |
| WinDivert | 使用内置驱动，以管理员权限运行 | 不希望额外安装 Npcap |
| Npcap | 安装 [Npcap](https://npcap.com/)，选择网卡 | 使用指定网卡，或 WinDivert 无法正常工作 |

## 3. 完成网络配置

**WinDivert**：确认选择此抓包方式，并以管理员权限重新运行。若驱动被安全软件拦截，请先查看 [抓包方式说明](./faq/app-runtime.md#抓包方式选-windivert-还是-npcap)。

**Npcap**：在 **网络设备** 中选择承载游戏流量的真实以太网或 Wi-Fi 网卡。不要选择 Loopback、VirtualBox 或 VMware 等虚拟网卡。若使用 VPN 或代理，先确认流量实际经过的设备。

## 4. 完全退出并重启

> **重要**：更换抓包方式或网卡后，必须完全退出并重新启动应用。关闭主窗口可能只是隐藏到托盘，请从托盘退出后再启动。

## 5. 验证战斗数据

1. 启动游戏，进入可战斗场景。
2. 打开 **DPS检测** 实时窗口并进行一次攻击。
3. 确认窗口中出现角色及伤害数据。若在游戏中途启动应用，切换场景一次以同步状态。

## 6. 没有数据时排查

依次检查游戏是否运行、所选抓包方式、驱动或网卡配置，并确认已经重启应用。详细排查见 [没有数据 / 抓不到包怎么办？](./faq/app-runtime.md#没有数据--抓不到包怎么办)。
