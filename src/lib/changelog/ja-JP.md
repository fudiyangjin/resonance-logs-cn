# Changelog v0.3.1

## 更新内容

### スキルダメージ表示

- スキルグループに「表示モード」を追加しました。「合算表示モード」はこれまでの表示です。新しい「連続表示モード」では、加算され続ける 1 つの数値だけを表示し、ウィンドウ終了時に合計のアニメーションを再生します（[@nekoyama32767](https://github.com/nekoyama32767)）。
  - 「ウィンドウの条件」で、累計の開始と精算のタイミングを決めます。
    - ローリング：グループ内スキルの命中で累計を始め、命中のたびに計時し直し、「連続ウィンドウ」の秒数内に新しい命中がなければ精算します。
    - スキルで開始・終了：「開始するダメージスキル」と「終了するダメージスキル」を指定します（どちらも複数選択可。開始スキルを指定しない場合は、グループ内のどのスキルの命中でも開始します）。終了スキルが命中するとすぐ精算し、命中しなければ「タイムアウト」で精算します。開始スキルが再び命中すると計時し直し、それまでの累計ダメージと連撃数は保持します。
    - 持続詠唱プリセット：現在は「寒氷射線」と「灌注（森語者）」です。自分の詠唱開始・終了でウィンドウを開閉し、タイムアウトはありません。「終了後の待機時間」（0～1 秒）を設定すると、詠唱終了後もしばらく累計してから精算します。
  - 「自身の全ダメージを累計」をオンにすると、ウィンドウ内のほかのスキルのダメージも累計ダメージと連撃数に含めます。ただし、ウィンドウを開始・更新するのはグループ内スキルの命中だけです。
  - 累計中と終了合計のアニメーションを別々に選べ、終了合計の表示時間も設定できます。
  - 連撃数を `1 HIT` または `×1` の形式で、数値の上・下・左・右に表示でき、数値との間隔も調整できます。
- スキルグループに「自身の全ダメージを表示」を追加しました。自分のすべてのスキルダメージをこのグループのダメージとして扱うため、スキルを 1 つずつ追加する必要はありません。どちらの表示モードでも使えます。
- 「複数ヒットの合計ダメージを表示」がオフのときは、ヒットごとに 1 件ずつ表示するようになりました（以前は同じバッチで最大の 1 ヒットだけを表示していました）。

### 音声読み上げ

- 「残り x 秒」「完了 x 秒前」の読み上げで、秒数の横に 2 つのスイッチを追加しました（どちらも既定でオフ）。
  - 「先に言い終える」：音声の長さだけ早く話し始め、残り x 秒でちょうど言い終えます（3 秒の音声を 5 秒に設定すると、残り 8 秒で話し始めます）。
  - 「カウントダウン」：音声の後、残り秒数を 1 秒ごとに読み上げます。各数字はその秒ちょうどに鳴り、最大 10 から数えます。「先に言い終える」と併用すると x から、単独の場合は音声が終わった後に残っている整数秒から数えます。
  - カウントダウンはほかの読み上げと重ねて再生され、互いを待ちません。同時に数えるカウントダウンは 1 つだけで、優先度の高いものが引き継げます。
  - カウントダウンは実際の残り時間に従います。Buff の更新、クールダウン短縮、ギミックの再発動があると、残りの数字はすぐに止まり、新しい時間が x 秒になったときに読み上げとカウントダウンをやり直します。対象が消えた場合はそのまま止まります。
- 音声読み上げ › マッチ通知 の一番下に「カウントダウンの数字」を追加しました。数字の音声はアプリに同梱されています。「数字の音声」を「自分で生成」にすると、自分の音声で 1 セット生成できます。自分で生成した数字はプリセットとは別に保存されるので、いつでも「プリセット」に戻せます。まだ生成していない数字はプリセットで読み上げます。

### モンスターモニター

- 戦闘リストの注目スキルの音声に「完了 x 秒前に読み上げ」を追加しました（モンスターモニター › 戦闘リスト › 注目スキル › 音声読み上げ）。行末の灰色のカウントダウンに合わせ、残り x 秒になったときに読み上げます。
  - 開戦直後の初回使用までの窓と、使用後のクールダウンの両方を読み上げます。
  - モンスターごとに数えます。2 秒以内に続けて来るものは 1 回にまとめます。
  - 「先に言い終える」「カウントダウン」と組み合わせられます。
  - モンスターが倒れるかリストから外れると読み上げず、途中のカウントダウンも止まります。早めに再使用された場合は、新しい使用時刻から数え直します。
  - 「発生時に読み上げ」と同じく、戦闘リストパネルを非表示にしても、「モンスターモニターを有効化」をオフにしても読み上げます。

### ライブモニター

- クラスの選択をページ上部の「プロファイル」に移しました（ライブモニター › プロファイル › 設定のクラス）。スキル CD とクラスリソースはこの 1 つのクラスを共用します。スキル CD とリソース設定の「設定のクラスを変更」からここへ移動でき、リソースをオフにしても現在のクラスが表示されます。
  - 複数のロードアウトが同じモニター設定を使う場合は、共有先が表示されます。クラスを変更するときに「現在のプラン用に複製」を選ぶと、ほかのロードアウトは元の設定のままです。上部の「複製」でも、モニター設定全体を現在のロードアウト専用に複製できます。
  - クラスを変更する前に、監視中のスキルやスキル音声があれば、クリアされる数を先に表示します。キャンセルすると何も変更しません。ほかのモニター内容とリソース配置は保持されます。
- ツインストライカーの赤痕オーブをリソースバーから分け、独立した「赤痕オーブ」区分にしました。単独でドラッグ・拡大縮小できます。赤痕オーブだけを表示したい場合は、リソースバー・リソースポイント・職業カウンターを非表示にします。

### DPS

- チャレンジ監視をグループ単位の管理に変更しました（DPSメーター › チャレンジ監視）。チャレンジごとに 1 グループで、グループは現在のロードアウトに属し、ロードアウトをエクスポートすると一緒に含まれます。
  - 内蔵プリセットはクリックするとグループとして追加されます。「新しいグループ」を作り、「ダメージを追加」でギミック名・ダメージ名・ダメージ ID から検索することもできます。ID は前方一致で（例：「#110098」、`#` は省略可）、結果が多いときはページを送れます。完全な ID を入力して Enter を押すと、名前の付いていないダメージも直接追加できます。
  - グループ内の各ダメージは「名前 #ID」で表示されるため、同じ名前の別ダメージも区別できます。
  - グループの「マイプリセットに保存」を押すと、どのロードアウトからでも「マイプリセット」からワンクリックで追加できます。プリセットはテンプレートで、追加すると独立したグループになり、あとでプリセットを変更しても追加済みのグループには影響しません。マイプリセットから追加したグループを編集したら、「マイプリセットを更新」で変更をプリセットに保存できます。
  - 赤い三角のツールチップに、受けたダメージをグループごとに名前・ID・命中回数付きで表示します。
- 回復と被ダメージのスキル詳細にも「ID」列を追加しました（ライブと履歴の両方）。DPS と同じく初期状態では非表示で、DPSメーター › 設定 の「回復（スキル詳細）列」「被ダメージ（スキル詳細）列」でオンにできます。被ダメージの ID で同名のモンスタースキルを区別でき、チャレンジ監視に追加するダメージ ID も調べられます。
- スキル詳細で同じ名前のスキルは、名前の後ろに `#ID` を表示して区別します。スキルグループに属さないスキル（モンスターのダメージなど）も同様に表示するようになりました。ID 列がオンのときは名前の後ろに ID を重ねて表示しません（コンパクトモードは名前の欄だけなので、引き続き名前の後ろに表示します）。
- DPSメーター › 設定 › ライブ に「除外対象」を追加しました。これらのモンスターへのダメージは DPS 統計と履歴に含めません。これらだけを攻撃しても戦闘は始まらず、訓練用ダミーの「最初のモンスター命中」でもロックされません。
  - 内蔵プリセット「渓流の異影のダミー（奥義！シャークトルネード）」（#3000090）をワンクリックで追加できます。この戦闘幻想が置く敵対ダミーは受けたダメージの一部を周囲のモンスターへ転送するため、ダミーへの攻撃自体は実際の火力ではありません。転送されたダメージは引き続き召喚者の分として集計され、スキル一覧にはダミーのパッシブとして表示されます。
  - 名前またはモンスター ID で検索して追加することもでき、表にない数値 ID もそのまま追加できます。
  - 除外リストは DPS 設定のプロファイルに保存され、ロードアウトの切り替えとエクスポートに従います。

### パケットキャプチャ

- パケットキャプチャを作り直しました。パケットの受信と、再構成・解析を別々のスレッドで行うため、解析や画面が忙しくても受信が遅れず、高負荷時（ゲームのバックグラウンドダウンロード中やプロキシ使用時など）の取りこぼしを減らします。
- パケットの再送後にストリームの再構成が止まり、その後の戦闘データが長時間欠けたり重複したりすることがある問題を修正しました。
- ゲームの接続をより正確に見分けます。ダウンロードなど、ゲームプロセスのほかの接続は接続の最初で判別して無視し、解析に回しません。
- Npcap モードでは無差別モードをオフにし、データを含まない確認応答パケットをドライバー側で除外します。
- ログに 1 分ごとのキャプチャ統計を記録します。ゲームが接続を持っているのに長時間ゲームデータを取得できない場合は、Npcap のアダプター選択を確認するようログで案内します（プロキシ使用時は TUN / VPN アダプターを選択してください）。

## 注意事項

- 「残り x 秒」「完了 x 秒前」の補完読み上げのルールが変わりました。残り時間が更新（クールダウン短縮、Buff の短縮、ギミックの再発動など）で x 秒をわずかに（1.5 秒以内）過ぎた場合だけ、その場で読み上げます。それ以上過ぎた場合（5 秒設定で残り 3 秒など）や、ほかの音声の後ろで 1.5 秒以上待った場合は読み上げません。
- 「先に言い終える」には音声の長さが必要です。音声が未生成の間は早めません。
- 更新後、赤痕オーブはリソースバーの下に表示されます。好きな位置へドラッグしてください。リソースバーの範囲はバー本体だけになります。ツインストライカーで位置を保存していないリソースポイントと職業カウンターは 1 段下に移動します。
- ライブモニターでクラスを変更すると、監視中のスキルとスキル音声がクリアされます。複数のロードアウトが同じ設定を共有している場合は、すべてに反映されます。ほかのロードアウトに影響させたくない場合は「現在のプラン用に複製」を選んでください。
- 既存の禁止ダメージは自動でグループに変換されます。内蔵プリセットに含まれるものはそのプリセットのグループに、残りは名前のない 1 つのグループにまとめます。
- 「除外対象」は初期状態では空なので、自分で追加してください。ダメージ数値オーバーレイとカウンターには影響せず、これらの命中も表示・集計されます。変更はそれ以降の命中にのみ適用され、保存済みの履歴は変わりません。
- 戦闘リストの「完了 x 秒前に読み上げ」は、行末の灰色のカウントダウンと同じく「最も早く使える時刻」の下限です。その時点で必ず使うとは限りません。x がクールダウンや開戦時の窓そのもの以上のときは、その区間は読み上げません。クールダウンのデータも開戦時の窓もないスキルは読み上げません。クールダウン秒数を入力すると有効になります。


### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.3.1 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.2 と 0.2.1 は大規模な再構築を行っています。既存機能に問題があれば速やかにご連絡ください
- 0.2.2 はテーブルフィールドを変更しています。古い履歴レコードのエラーは想定どおりで、新しい記録は正常です
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません。HTTP 音声サービスではモデルは不要です
