# Changelog v0.2.8

## 更新内容

### ライブモニター

- 職業リソース表示をゲーム内の見た目に合わせて作り直し、全職業に対応しました（ライブモニター › ウィンドウを有効化 › リソース区分）。リソースエリアをリソースバー、リソースポイント、シールドバー、職業カウンターに分け、ブロックごとに表示 / 非表示とドラッグができます。
  - リソースバーの枠の上のカラーバーはクラスバフの残り時間です。ツインストライカーの赤痕オーブ、ディバインアーチャーの狼 / 鷹の枠、ビートパフォーマーの演奏バーもここに表示されます。
  - シールドバーはシールドファイターの「光明の盾」中に出る縦のバーです。
  - 職業カウンターはゲーム画面のスタック数、ゲイルランサーの風紋、ストームブレイドの特殊雷印、ツインストライカーの評価文字などを再現します。これまで Buff エリアでスタック数に応じて変わっていたアイコン（ゲイルランサー「追撃身法」など）はここに表示されます。
  - 「リソース文字」を追加し、リソースバー・リソースポイント・シールドバーの数字のサイズと色を調整できます。

  ![各クラスのリソースバーとリソースポイント](/images/changelog/v0.2.8_1.ja-JP.png)

- 複合 Buff に表示方法「最も急ぐメンバー」を追加しました（ライブモニター › Buff モニター › 複合 Buff › 表示方法）。いずれかのメンバーが存在する間は 1 枠だけ表示し、欠けているメンバーがいればグレー表示で「欠落」と表示、いなければ残り時間が最も短いメンバーを表示します。属性交響のように複数の Buff を順に掛け直す場合に便利です。
  - 音声は複合全体の出現・消失・終了間近で鳴ります。特定のメンバーだけ通知したい場合は、そのメンバー自身に音声を設定してください。
  - 複合はメンバー自身の表示を隠しません。メンバーを別のエリアにも追加している場合は、そちらにもそれぞれ表示されます。

  ![全メンバーがそろっているときは最も早く切れるメンバーを表示](/images/changelog/v0.2.8_2.ja-JP.png)

  ![欠けているメンバーを通知](/images/changelog/v0.2.8_3.ja-JP.png)

- スキルのチャージ数は使用可能な数だけを表示し、アイコンに合わせて拡大縮小するようにしました。味方 CD のアイコンが小さいときにチャージ数がアイコンより大きくなる問題を修正し、チャージ中の時間表示もなくしました。自分のスキル CD と味方 CD の両方に適用されます。
- 街でゲームオーバーレイが自動的に隠れている間にロードアウトを切り替えると、新しく付いたアイコン付き Buff が編集モードを一度切り替えるまで表示されない問題の修正を試みました（Svelte フレームワークのバージョンを更新）。

### DPS / 履歴

- リアルタイムウィンドウで履歴を見ているとき、上部バナーに「バフ稼働率」ボタンを追加しました。プレイヤー欄でプレイヤーを選ぶと、その戦闘での各 Buff の稼働率と発動回数を確認できます。プレイヤーは自分、ヒーラー、タンク、アタッカーの順に並びます。
  - 記録されるのは ライブモニター › バフ稼働率 で追加した Buff のみで、追加した後の戦闘から記録されます。
  - 稼働率ページで前 / 次の戦闘に切り替えても、稼働率ページのままです。ボタンをもう一度押すと元の統計ページに戻ります。

  ![履歴バナーのバフ稼働率ボタン](/images/changelog/v0.2.8_4.ja-JP.png)

  ![リアルタイムウィンドウで履歴戦闘のバフ稼働率を表示](/images/changelog/v0.2.8_5.ja-JP.png)

### モンスターモニター

- モンスタースキルに「カウントダウン」を追加しました（モンスターモニター › モンスタースキル）。オンにすると表示秒数をカウントダウンとして扱い、残り秒数とプログレスバーを表示し、0 になると消えます。
  - 「スキル A の数秒後に必ずスキル B が来る」場合の予告に使えます。A をリストに追加し、別名に B、表示秒数に間隔を設定してください。
- モンスタースキルパネルのスタイルに、列間隔、値の色、プログレスバー色、プログレスバー不透明度を追加しました。

### ダンジョンギミック

- マップパネルとギミック通知の背景の濃度を個別に調整できるようになりました（ダンジョンギミック › ミニマップギミック › パネル表示）。0 にするとマップは線・ギミック範囲・人物の点だけ、ギミック通知は文字だけになります。
- S4「蒼穹の上、昼夜の果て」（テスト機能）
  - 各ギミックの音声通知を追加しました。ダンジョンギミック › ミニマップギミック › ギミック音声通知 で設定できます（[@nekoyama32767](https://github.com/nekoyama32767)）。
  - 1 ボス目の符文輪盤の符文がまったく表示されない問題を修正しました。連戦のギミックも追加し、符文輪盤上で点灯中のスロットを表示、小金人を対応する符文の色で表示、ギミック通知にボスの符文の点灯順とチャージ間隔を表示します。
  - 3 ボス目の天体衝突：球 2 つの場合は球が出現した時間から爆発位置と時間を予測するようにしました。球 3 つの場合は ①② の立ち位置と移動ルートだけを描き、ギミック通知で 1 回目 / 2 回目の爆発までカウントダウンします（光 2 つ・闇 1 つのとき）。

  ![1 ボス目の符文輪盤と連戦のギミック通知](/images/changelog/v0.2.8_6.png)

  ![ボスの符文の点灯順](/images/changelog/v0.2.8_7.png)

### 音声

- 機能ページで文面が「自動生成」または「カスタムテキスト」の読み上げは、「生成する音声」でその 1 件だけ使う音色や HTTP サービスを指定できます。「カスタムテキスト」では「生成言語」も指定でき、「音声を生成」ボタンですぐ生成できます（[@nekoyama32767](https://github.com/nekoyama32767)）。
- 「不足分の音声を一括生成」の完了時に成功件数と失敗件数を表示し、失敗した理由は該当する読み上げの下に表示するようにしました。
- ローカル音声モデルで短いフレーズの生成がまれに止まらず、メモリ / VRAM 使用量が急増する問題を修正しました。生成の長さを文字数に応じて制限し、超えた場合は最大 3 回まで自動で再試行します。
- アプリ起動後にヘッドホンなど別の出力デバイスへ切り替えても、音声が元のデバイスから再生される問題の修正を試みました（音声再生フレームワーク rodio / cpal のバージョンを更新）。

- リソース区分（各クラスのリソースバーと職業カウンターの例図）、モンスタースキルのカウントダウン、ダンジョンギミックの背景濃度の説明を更新しました。

## 注意事項

- 職業カウンターは Buff エリアには表示されなくなり、リソースエリアの「職業カウンター」区分に表示されます。リソースモニターエリアを有効にしている場合のみ表示されます。シールドバーや職業カウンターなどの新しい区分は、最初はリソースエリアの元の位置の下に並ぶので、編集モードで適切な位置へドラッグしてください。
- 「最も急ぐメンバー」はメンバー自身の表示を隠しません。1 枠だけにしたい場合は、それらのメンバーを他のエリアから削除してください。


### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.2.8 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.2 と 0.2.1 は大規模な再構築を行っています。既存機能に問題があれば速やかにご連絡ください
- 0.2.2 はテーブルフィールドを変更しています。古い履歴レコードのエラーは想定どおりで、新しい記録は正常です
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません。HTTP 音声サービスではモデルは不要です

### 特に注意

- コードを改変して PR せずに配布する場合は、アプリ名・バージョンなど本家の識別情報を必ず変更し、誤解を招かないようにしてください
- 閉じるボタンは右下に隠れます。ウィンドウが多い場合は隠れバーを右下へドラッグして表示できます
- よくある質問は利用マニュアルの HTML を参照してください
