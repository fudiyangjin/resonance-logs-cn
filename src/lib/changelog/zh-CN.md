# Changelog v0.3.1

## 更新内容

### 技能伤害显示

- 技能组新增「显示模式」：「合并显示模式」就是原来的显示方式；新增「连续显示模式」，只显示一条不断累加的伤害，窗口结束后播放总计动画（[@nekoyama32767](https://github.com/nekoyama32767)）
  - 「窗口规则」决定何时开始累计、何时结算：
    - 滚动窗口：组内技能命中后开始累计，每次命中重新计时，「连续窗口」秒数内没有新的命中就结算
    - 技能触发窗口：指定「窗口开启技能」和「窗口结束技能」（都可多选；不指定开启技能时，组内任意技能命中即开启），结束技能命中后立即结算，否则按「窗口超时」结算；再次命中开启技能会重新计时，已累计的伤害和连击数保留
    - 持续施法预设：目前提供「寒冰射线」和「灌注（森语者）」，按自己的施法开始、结束开关窗口，不设超时；可设置「窗口关闭延迟」（0～1 秒），施法结束后再多累计一会儿才结算
  - 开启「累计所有自身伤害」后，窗口内其他技能的伤害也计入累计伤害和连击数，但只有组内技能命中才会开启或刷新窗口
  - 累计中和结束总计可以分别选择动画，并设置总计的显示时间
  - 可以显示连击数，格式可选 `1 HIT` 或 `×1`，可放在数字的上、下、左、右，并调整与数字的间隔
- 技能组新增「显示所有自身伤害」：把自己所有技能的伤害都当作本组伤害，不用逐个添加技能；两种显示模式都可以使用
- 关闭「多次命中合并总伤害」时改为逐条显示每次命中（之前只显示同一批次中最大的一次）

### 语音播报

- 「剩 x 秒」「就绪前 x 秒」类播报的秒数旁新增两个开关，默认都不勾选：
  - 「提前念完」：按语音长度提前开口，在剩 x 秒时正好念完（3 秒的语音设 5 秒，会在剩 8 秒时开口）
  - 「倒数」：语音念完后逐秒倒数，每个数字落在对应的那一秒上，最多从 10 开始数。和「提前念完」一起勾选时从 x 开始数；只勾选这一项时，从语音念完后剩下的整秒开始数
  - 倒数和其他语音同时播放，互不等待；同一时刻只有一个倒数在数，优先级更高的可以接管
  - 倒数跟着对象的真实剩余时间走：Buff 被续上、技能被减 CD、机制重新触发时，没数完的数字立即停下，等新的时间走到 x 秒时重新播报并倒数；对象消失则直接停止
- 语音播报-匹配提醒 页底部新增「倒数数字」：倒数用的数字随应用自带；把「数字来源」改为「自己生成」，可以用自己的音色生成一套。自己生成的数字和预置数字分开保存，随时可以切回「预置」；还没生成的数字仍然播放预置

### 怪物监控

- 战斗名单的关注技能语音新增「就绪前 x 秒播报」（怪物监控-战斗名单-关注技能-语音播报）：跟着行尾的灰色倒计时走，剩 x 秒时播报
  - 开战首放窗口和放过之后的冷却都会播报
  - 每只怪各算各的；几只怪在 2 秒内先后到点只播一句
  - 可以配合「提前念完」「倒数」使用
  - 怪死亡或离开名单后不再播报，没念完的倒数随之停止；怪提前再次施放时按新的冷却重新计时
  - 和「触发时播报」一样，名单面板隐藏、或关闭「启用怪物监控」后照常播报

### 实时监控

- 职业选择移到页面顶部的「配置方案」（实时监控-配置方案-配置职业），技能 CD 和职业资源共用这一个职业；技能 CD 和资源设置中的「更改配置职业」会跳到这里，关闭资源显示时也能看到当前职业
  - 多个总方案共用同一套监控配置时，会列出共用的方案；切换职业时可以选择「复制并仅用于当前方案」，其他方案继续使用原来的配置。顶部的「复制」也可以复制完整的监控配置，只给当前方案使用
  - 切换职业前，如果已有监控技能或技能语音，会先提示将清空的数量，取消则不做任何修改；其他监控内容和资源布局保持不变
- 赤炎狂战士的赤痕球从资源条中拆出，成为独立的「赤痕球」区域，可以单独拖动、缩放；只想看赤痕球时，把资源条、资源点和职业计数隐藏即可

### DPS

- 挑战监控改为按分组管理（DPS检测-挑战监控），一个挑战一组，跟随当前配装，导出配装时一起带走
  - 内置预设点一下就作为一个分组加入；也可以「新建分组」，再在「添加伤害」中按机制、伤害名称或伤害 ID 搜索。ID 支持前缀，如「#110098」（`#` 可省略），结果多时可以翻页；输入完整 ID 后按回车，可以直接添加表里没有名称的伤害
  - 分组里的每个伤害都显示为「名称 #ID」，同名的不同伤害也能分清
  - 在分组上点「存为我的预设」，之后在任何配装中都能从「我的预设」一键添加。预设只是模板，添加后得到一份独立的分组，之后修改预设不会影响已添加的分组；修改了由「我的预设」添加的分组后，可以点「更新我的预设」把改动存回去
  - 红色三角的悬停提示按分组列出命中的伤害，每一项都带名称、ID 和命中次数
- 治疗和承伤的技能明细也新增「ID」列（实时和历史都有），和 DPS 一样默认隐藏，可在 DPS检测-设置 的「治疗（技能明细）列」「承伤（技能明细）列」中开启；承伤的 ID 可以区分同名的怪物技能，也方便查到挑战监控要添加的伤害 ID
- 技能明细中同名的技能会在名字后显示 `#ID` 加以区分，现在不在技能组里的技能（如怪物伤害）也会这样显示；开启 ID 列后名字后不再重复显示 ID（紧凑模式只有名字一栏，ID 仍显示在名字后）
- DPS检测-设置-实时 新增「排除目标」：打到这些怪物的伤害不计入 DPS 统计和历史记录；只打它们不会开始一场战斗，打桩的「首次命中怪物」也不会锁定到它们
  - 内置预置「涧流的异影木桩（奥义！鲛旋湍流）」（#3000090），点一下即可添加。这个战斗幻想摆出的敌对木桩会把受到的部分伤害转给周围怪物，打木桩本身不是真实输出；转出去的伤害照常算在召唤者名下，技能列表里显示为「鲨鱼王-木桩被动」
  - 也可以按名称或怪物 ID 搜索添加，表里查不到的纯数字 ID 也能直接添加
  - 排除列表保存在 DPS 设置方案中，随总方案切换和导出

### 抓包

- 重写抓包流程：收包与数据重组、解析分到不同的线程，解析或界面繁忙时不再拖慢收包，减少高负载（如游戏在后台下载、开着代理）时的漏包
- 修复数据包重传后数据重组可能卡住，导致之后的战斗数据长时间缺失或重复的问题
- 更准确地区分游戏连接：游戏进程的下载等其他连接在连接开头就会被识别并忽略，不再进入解析
- Npcap 模式关闭混杂模式，并在驱动层过滤掉不带数据的确认包
- 日志每分钟记录一次抓包统计；游戏有连接却长时间抓不到游戏数据时，日志会提示检查 Npcap 网卡选择（开代理时请选择 TUN / VPN 网卡）

## 注意事项

- 「剩 x 秒」「就绪前 x 秒」的补播规则有变化：剩余时间被更新（减 CD、Buff 被缩短、机制重新触发）后刚好越过 x 秒、且越过不超过 1.5 秒时才立即补播；越过得更多（比如设 5 秒却只剩 3 秒）不再补播，排队等前一条语音超过 1.5 秒的也不再播
- 「提前念完」需要知道语音长度，语音还没生成时按不提前处理
- 升级后赤痕球默认出现在资源条下面，需要自己拖到想要的位置；资源条的区域只包住资源条本身。赤炎狂战士没有保存过位置的资源点和职业计数会往下挪一格
- 实时监控切换职业会清空监控技能和技能语音；多个方案共用同一套配置时，修改会同时影响它们，不想影响其他方案请选择「复制并仅用于当前方案」
- 原有的挑战禁用伤害会自动转成分组：属于内置预设的归入对应的预设分组，其余的合成一个未命名分组
- 「排除目标」默认为空，需要自己添加；伤害数字浮窗和计数器不受影响，仍会显示、计入这些命中；修改只影响之后的命中，已保存的历史记录不会改变
- 战斗名单的「就绪前 x 秒播报」和行尾的灰色倒计时一样，是「最早可放」的下限，到点后怪不一定马上放；x 不小于冷却或首放窗口本身时，这一段不播报；既没有冷却数据、也没有首放窗口的技能不会播报，填写冷却秒数后生效
